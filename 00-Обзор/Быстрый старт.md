# Быстрый старт

## Требования

- Docker 20.10+ с BuildKit
- Docker Compose
- 8GB+ RAM (рекомендуется 16GB)
- 4+ CPU cores (рекомендуется 8)
- 20GB+ свободного места
- Linux (Ubuntu 22.04+)

## Установка

```bash
git clone https://github.com/RedAlexDad/WalkingRobotSim.git
cd WalkingRobotSim
make deploy    # сборка + запуск (15-30 мин первая сборка)
```

## Основные команды

### Управление контейнером

```bash
cd src/docker

# Запуск
docker compose up -d

# Остановка
docker compose down

# Логи
docker compose logs -f

# Вход в контейнер
docker compose exec simulator bash
```

### Через Makefile

```bash
make build       # сборка Docker образа
make up          # запуск контейнера
make up-bg       # запуск в фоне (без ожидания ROS)
make down        # остановка
make restart     # перезапуск
make clean       # удаление контейнера и образа
```

### Запуск симуляции

```bash
# Запуск с Python контроллером (быстрая итерация, обучение)
make gazebo-py

# Запуск с C++ контроллером (продакшен, производительность)
make gazebo-cpp

# Запуск с C++ контроллером (по умолчанию)
make gazebo
```

### Телеоперация

```bash
make teleop      # клавиатурное управление
```

### Интерактивная работа

```bash
make shell       # интерактивная оболочка
make exec        # выполнить команду в контейнере
make kill-ros    # остановить все ROS процессы
```

### Управление контейнером

```bash
make backup      # бэкап
make status      # статус контейнера
make logs        # логи контейнера
make help        # справка по всем командам
```

### Внутри контейнера

```bash
sim     # запуск симуляции Gazebo
teleop  # клавиатурное телеоперация
topics  # список ROS топиков
nodes   # список ROS узлов
```

### Управление роботом

```bash
# Переключение режима на TROT
ros2 topic pub /robot1/robot_mode quadropted_msgs/msg/RobotModeCommand "{mode: 'TROT', robot_id: 1}"

# Переключение режима на STAND (вращение на месте)
ros2 topic pub /robot1/robot_mode quadropted_msgs/msg/RobotModeCommand "{mode: 'STAND', robot_id: 1}"

# Переключение режима на REST
ros2 topic pub /robot1/robot_mode quadropted_msgs/msg/RobotModeCommand "{mode: 'REST', robot_id: 1}"

# Переключение режима на CRAWL
ros2 topic pub /robot1/robot_mode quadropted_msgs/msg/RobotModeCommand "{mode: 'CRAWL', robot_id: 1}"

# Сервис поведения (sit/up/walk)
ros2 service call /robot1/robot_behavior_command quadropted_msgs/srv/RobotBehaviorCommand "{command: 'walk'}"
ros2 service call /robot1/robot_behavior_command quadropted_msgs/srv/RobotBehaviorCommand "{command: 'sit'}"
ros2 service call /robot1/robot_behavior_command quadropted_msgs/srv/RobotBehaviorCommand "{command: 'up'}"
```

### Переключение между Python и C++

| Действие | Python | C++ |
|----------|--------|-----|
| Запуск | `make gazebo-py` | `make gazebo-cpp` |
| Главный узел | `robot_controller_gazebo.py` | `robot_controller_node` |
| Однометрия | `QuadrupedOdometryNode.py` | `odometry_node` |
| Тесты | `pytest test/` | `colcon test` |
| Бенчмарки | `python benchmark_*.py` | `./build/.../benchmark` |
