# Быстрый старт

## Требования

- Docker 20.10+ с BuildKit
- Docker Compose
- 8GB+ RAM (рекомендуется 16GB)
- 4+ CPU cores (рекомендуется 8)
- 20GB+ свободного места
- Linux (Ubuntu 22.04+)

## Установка

```bash
git clone https://github.com/RedAlexDad/WalkingRobotSim.git
cd WalkingRobotSim
cd src/docker
docker compose build    # 15-30 мин первая сборка
docker compose up -d    # запуск контейнера
```

## Основные команды

### Управление контейнером

```bash
cd src/docker

# Запуск
docker compose up -d

# Остановка
docker compose down

# Логи
docker compose logs -f

# Вход в контейнер
docker compose exec simulator bash
```

### Через manage.sh

```bash
./manage.sh build       # сборка
./manage.sh up          # запуск
./manage.sh down        # остановка
./manage.sh gazebo      # запуск Gazebo (C++ контроллер)
./manage.sh gazebo-py   # запуск Gazebo (Python контроллер)
./manage.sh teleop      # клавиатурное управление
./manage.sh shell       # интерактивная оболочка
./manage.sh kill-ros    # остановить все ROS процессы
./manage.sh backup      # бэкап
```

### Внутри контейнера

```bash
sim     # запуск симуляции Gazebo
teleop  # клавиатурное телеоперация
topics  # список ROS топиков
nodes   # список ROS узлов
```

### Управление роботом

```bash
# Переключение режима на TROT
ros2 topic pub /robot1/robot_mode quadropted_msgs/msg/RobotModeCommand "{mode: 'TROT', robot_id: 1}"

# Переключение режима на STAND (вращение на месте)
ros2 topic pub /robot1/robot_mode quadropted_msgs/msg/RobotModeCommand "{mode: 'STAND', robot_id: 1}"

# Переключение режима на REST
ros2 topic pub /robot1/robot_mode quadropted_msgs/msg/RobotModeCommand "{mode: 'REST', robot_id: 1}"

# Сервис поведения (sit/up/walk)
ros2 service call /robot1/robot_behavior_command quadropted_msgs/srv/RobotBehaviorCommand "{command: 'walk'}"
```
