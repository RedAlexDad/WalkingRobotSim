# Обзор проекта

## Описание

**WalkingRobotSim** — полнофункциональный симулятор четырёхногого робота (квадрупеда) на базе ROS 2 Jazzy с Docker-контейнеризацией. Симулирует роботов Unitree Go1 и Go2 в Gazebo с полным контролем локомоции (ходьба, ползание, стойка, покой), автономной навигацией через Nav2 и поддержкой нескольких роботов одновременно.

**Автор:** RedAlexDad (Алексей Папин, группа ИУ5Ц-11М)
**Тип:** Дипломный проект (НИРС)

## Двойная архитектура

Проект содержит **две параллельные реализации** контроллера:

### Python (`quadropted_controller/`)
- **Оригинальная реализация** -- с неё началась разработка
- **Быстрая итерация** -- легко прототипировать и отлаживать
- **Обучение** -- проще читать и понимать код
- **Когда использовать:** прототипирование, обучение, демонстрация

### C++ (`quadropted_controller_cpp/`)
- **Высокопроизводительная версия** -- в 25-40× быстрее
- **Продакшен** -- стабилен для реального робота
- **Меньше ресурсов** -- 3× меньше памяти, 2-3× меньше CPU
- **Когда использовать:** продакшен, реальный робот, CI/CD

### Кросс-валидация

Обе реализации имеют **идентичную функциональность** и подтверждённую **численную точность** через кросс-валидацию (38 тестов, отклонение `< 1e-8`).

Подробнее: [[Сравнение Python vs C++]], [[Кросс-валидация]]

## Ключевые компоненты

### Python реализация
1. **RobotController** — главный контроллер, конечный автомат переключения режимов
2. **Gait Controllers** — Trot, Crawl, Stand, Rest (стратегия)
3. **Inverse/Forward Kinematics** — расчёт углов сочленений и позиций стоп
4. **QuadrupedOdometryNode** — одометрия по контакту стоп
5. **PID Controller** — компенсация крена/тангажа по IMU

### C++ реализация
1. **robot_controller_node** — главный контроллер (60 Hz)
2. **odometry_node** — узел одометрии (50 Hz)
3. **cmd_vel_pub** — конвертер cmd_vel → RobotVelocity
4. **Kinematics** — FK/IK с Eigen3
5. **Controllers** — Trot, Crawl, Stand, Rest с PID компенсацией

### Общая инфраструктура
1. **Nav2** — автономная навигация с картой
2. **Gazebo** — физическая симуляция
3. **EKF** — фильтрация одометрии

## Режимы робота

| Режим | Описание |
|---|---|
| REST | Покой, робот неподвижен |
| TROT | Ходьба рысью (диагональные пары ног) |
| CRAWL | Ползание (последовательное движение ног) |
| STAND | Стойка (вращение на месте) |
