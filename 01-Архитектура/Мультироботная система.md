# Мультироботная система

## Описание

Система поддерживает одновременную симуляцию нескольких роботов Unitree Go1/Go2, каждый со своим Nav2 стеком и контроллерами.

## Конфигурация роботов

### Файл: `src/gazebo_sim/config/robots.yaml`

```yaml
robots:
  - name: robot1
    x_pose: '0.0'
    y_pose: '0.0'
    z_pose: '0.8'
  # - name: robot2
  #   x_pose: '-2.0'
  #   y_pose: '0.0'
  #   z_pose: '0.8'
```

### Параметры каждого робота

| Параметр | Описание |
|---|---|
| `name` | Namespace робота (robot1, robot2, ...) |
| `x_pose` | Координата X спавна в мире Gazebo |
| `y_pose` | Координата Y спавна в мире Gazebo |
| `z_pose` | Координата Z спавна (высота) |

## Архитектура namespace

Каждый робот работает в своём ROS 2 namespace:

```
/robot1/
├── /robot1/cmd_vel          # Команда скорости
├── /robot1/odom             # Одометрия
├── /robot1/joint_states     # Состояния сочленений
├── /robot1/robot_mode       # Режим работы
├── /robot1/robot_velocity   # Скорость робота
├── /robot1/foot_contact     # Контакты стоп
├── /robot1/scan             # Данные лидара
├── /robot1/robot_behavior_command  # Сервис поведения
└── Nav2 stack               # Навигация
    ├── /robot1/goal_pose
    ├── /robot1/costmap
    └── ...

/robot2/
├── ... (аналогично)
```

## Launch-процесс

`gazebo_multi_nav2_world.launch.py`:

1. Читает `robots.yaml`
2. Для каждого робота запускает:
   - `robot_state_publisher` (URDF с namespace)
   - GZ bridge (ROS ↔ Gazebo с namespace)
   - Joint state publisher
   - Controller manager (ros2_control)
   - RobotControllerNode
   - QuadrupedOdometryNode
   - Nav2 stack (полный набор)
   - EKF (robot_localization)

## Ограничения

- **CycloneDDS** — не поддерживает мультироботов в стандартной конфигурации (нужно настраивать)
- **Ресурсы** — каждый робот добавляет значительную нагрузку (Nav2 + Gazebo)
- **Координаты спавна** — роботы не должны перекрываться

## Идентификация робота

В кастомных сообщениях есть поле `robot_id`:

```python
# RobotModeCommand.msg
string mode
uint16 robot_id

# RobotVelocity.msg
uint16 robot_id
geometry_msgs/Twist cmd_vel
```

Контроллер фильтрует сообщения по `robot_id`:

```python
def mode_callback(self, msg):
    if msg.robot_id == self.robot_id:
        # Обработка команды
```
