# Crawl Gait Controller — Контроллер ползания

## Файл
`src/quadropted_controller/scripts/RobotController/CrawlGaitController.py`

## Описание

Реализует походку «ползание» (crawl) — ноги двигаются последовательно, по одной за раз. Медленнее, но стабильнее рыси.

## Параметры

| Параметр | Значение | Описание |
|---|---|---|
| `stance_time` | 0.55 с | Время фазы опоры |
| `swing_time` | 0.45 с | Время фазы переноса |
| `time_step` | 0.02 с | Шаг дискретизации |

### Лимиты скорости

| Ось | Максимум |
|---|---|
| X (вперёд) | 0.011 м/с |
| Yaw (поворот) | 0.15 рад/с |

### Фазы контакта (8 фаз)

```
        0  1  2  3  4  5  6  7
FR:     1  1  1  1  1  1  1  0
FL:     1  1  1  1  0  1  1  1
RR:     1  1  0  1  1  1  1  1
RL:     1  0  1  1  1  1  1  1
```

Каждая нога поднимается по очереди: RL → RR → FL → FR.

## Особенности

- **Смещение тела** — для боковой стабильности при ползании тело смещается в сторону опорных ног
- **8-фазный цикл** — каждая нога имеет свою фазу переноса
- **first_cycle** — флаг первого цикла для правильной инициализации
