# Gait Controller — Базовый класс походки

## Файл
`src/quadropted_controller/scripts/RobotController/GaitController.py`

## Описание

Абстрактный базовый класс для всех контроллеров походки. Определяет фазы контакта ног и тайминги цикла ходьбы.

## Конструктор

```python
GaitController(stance_time, swing_time, time_step, contact_phases, default_stance)
```

**Параметры:**
- `stance_time` — время фазы опоры (секунды)
- `swing_time` — время фазы переноса (секунды)
- `time_step` — шаг дискретизации (секунды)
- `contact_phases` — матрица контактов (4 ноги × N фаз)
- `default_stance` — позиция стойки по умолчанию (3×4)

## Свойства

| Свойство | Формула | Описание |
|---|---|---|
| `stance_ticks` | `int(stance_time / time_step)` | Тактов фазы опоры |
| `swing_ticks` | `int(swing_time / time_step)` | Тактов фазы переноса |
| `phase_ticks` | массив | Такты каждой подфазы |
| `phase_length` | `sum(phase_ticks)` | Общая длина цикла |

## Методы

### `phase_index(ticks)`
Определяет, в какой фазе цикла находится робот. Возвращает индекс текущей фазы (0..N-1).

### `subphase_ticks(ticks)`
Возвращает количество тактов с начала текущей фазы. Используется для вычисления прогресса внутри фазы.

### `contacts(ticks)`
Возвращает массив из 4 булевых значений — какие ноги должны быть в контакте с землёй. Берёт строку из `contact_phases` по индексу текущей фазы.

## Матрица contact_phases

Каждый столбец — фаза цикла. Каждая строка — нога. Значение 1 = контакт (stance), 0 = перенос (swing).

**Пример для Trot (4 фазы):**
```
        Фаза 0  Фаза 1  Фаза 2  Фаза 3
FR:       1       1       1       0
FL:       1       0       1       1
RR:       1       0       1       1
RL:       1       1       1       0
```

- Фаза 0: все ноги в контакте (начало цикла)
- Фаза 1: FL и RR в переносе (диагональная пара)
- Фаза 2: все ноги в контакте
- Фаза 3: FR и RL в переносе (диагональная пара)
