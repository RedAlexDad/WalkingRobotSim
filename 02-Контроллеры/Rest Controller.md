# Rest Controller — Контроллер покоя

## Файл
`src/quadropted_controller/scripts/RobotController/RestController.py`

## Описание

Контроллер состояния покоя — робот неподвижен, все ноги в позиции default_stance. Поддерживает компенсацию крена/тангажа через PID.

## Параметры PID

| Параметр | Значение |
|---|---|
| kp | 0.75 |
| ki | 2.29 |
| kd | 0.0 |

## Принцип работы

- Возвращает `default_stance` с фиксированной высотой (`command.robot_height`)
- При включённом IMU применяет PID-компенсацию крена/тангажа
- Не двигает ноги, только корректирует ориентацию тела
