# Stand Controller — Контроллер стойки

## Файл
`src/quadropted_controller/scripts/RobotController/StandController.py`

## Описание

Контроллер стойки — робот стоит на месте, но может вращаться и смещать тело. Используется для вращения на месте.

## Параметры

| Параметр | Значение | Описание |
|---|---|---|
| `max_reach` | 0.065 | Максимальное смещение |
| `body_velocity_scale` | 0.01 | Масштаб линейных скоростей |
| `body_angular_scale` | 0.005 | Масштаб угловых скоростей |
| `max_linear_velocity` | 0.035 м/с | Макс. линейная скорость |
| `max_angular_velocity` | 0.1 рад/с | Макс. угловая скорость |

## Принцип работы

- Позиции стоп фиксированы (default_stance)
- Команды скорости интегрируются в `body_local_position` и `body_local_orientation`
- Обратная кинематика вычисляет углы сочленений для смещённого тела
