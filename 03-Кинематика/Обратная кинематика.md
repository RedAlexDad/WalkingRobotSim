# Обратная кинематика (Inverse Kinematics)

## Файл
`src/quadropted_controller/scripts/InverseKinematics/robot_IK.py`

## Описание

Вычисляет 12 углов сочленений (по 3 на каждую ногу) по заданным позициям стоп. Использует аналитический геометрический подход с теоремой косинусов.

## Класс `InverseKinematics`

### Конструктор

```python
InverseKinematics(bodyDimensions, legDimensions)
```

**Параметры:**
- `bodyDimensions` — [длина, ширина] = [0.3762, 0.0935]
- `legDimensions` — [l1, l2, l3, l4] = [0.0, 0.0955, 0.213, 0.213]

### Методы

#### `get_local_positions(leg_positions, dx, dy, dz, roll, pitch, yaw)`

Преобразует глобальные позиции стоп в локальные координаты системы плеча каждой ноги.

**Матрицы преобразования:**
- `T_blwbl` — base_link_world → base_link
- `T_blwFR1`, `T_blwFL1`, `T_blwRR1`, `T_blwRL1` — base_link_world → база каждой ноги

Для каждой ноги:
```
pos_local = T_blw_leg^(-1) × leg_position_world
```

#### `inverse_kinematics(leg_positions, dx, dy, dz, roll, pitch, yaw)`

Основной метод. Возвращает 12 углов сочленений.

**Алгоритм для каждой ноги:**

```python
# 1. Локальные координаты стопы
x, y, z = local_position

# 2. Угол hip (abduction/adduction)
F = sqrt(x² + y² - l2²)
G = F - l1
H = sqrt(G² + z²)
theta1 = -atan2(y, x) - atan2(F, l2 * (-1)^i)

# 3. Угол calf (по теореме косинусов)
D = (H² - l3² - l4²) / (2 * l3 * l4)
theta4 = -atan2(sqrt(1 - D²), D)

# 4. Угол thigh
theta3 = atan2(z, G) - atan2(l4*sin(theta4), l3 + l4*cos(theta4))
```

**Выход:** `[FR_hip, FR_thigh, FR_calf, FL_hip, FL_thigh, FL_calf, RR_hip, RR_thigh, RR_calf, RL_hip, RL_thigh, RL_calf]`

## Геометрия ноги

```
         hip (θ1)
          │
      ┌───┴───┐
      │       │
    shoulder  l2 (thigh)
      │       │
      │    ┌──┴──┐
      │    │     │ θ3 (thigh)
      │    └──┬──┘
      │       │
      │    l3 (calf)
      │       │
      │    ┌──┴──┐
      │    │     │ θ4 (calf)
      │    └──┬──┘
      │       │
      │    l4 (foot)
      │       ▼
      │    [end effector]
```

## Использование

Основной потребитель — [[Robot Controller]], который в `robot_controller_gazebo.py` вызывает IK на каждом шаге control_loop (60 Гц) для преобразования позиций стоп в углы сочленений.
