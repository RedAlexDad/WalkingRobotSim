# Прямая кинематика (Forward Kinematics)

## Файл
`src/quadropted_controller/scripts/ForwardKinematics/robot_FK.py`

## Описание

Вычисляет позиции стоп (x, y, z) для всех 4 ног по 12 углам сочленений. Использует цепочку однородных матриц преобразования 4×4.

## Класс `ForwardKinematics`

### Конструктор

```python
ForwardKinematics(body_dimensions, leg_dimensions)
```

**Параметры:**
- `body_dimensions` — [длина, ширина] корпуса = [0.3762, 0.0935]
- `leg_dimensions` — [l1, l2, l3, l4] = [0.0, 0.0955, 0.213, 0.213]
  - `l1` — высота корпуса (от центра масс до основания ног)
  - `l2` — длина бедра
  - `l3` — длина голени
  - `l4` — длина копыта

### Методы

#### `homog_transform(dx, dy, dz, alpha, beta, gamma)`
Создаёт однородную матрицу 4×4: `T = trans × Rz × Ry × Rx`

#### `forward_kinematics_per_leg(theta_hip, theta_thigh, theta_calf, leg_index)`
Вычисляет позицию одной ноги.

**Индексы ног:**
- 0 — FR (front-right)
- 1 — FL (front-left)
- 2 — RR (rear-right)
- 3 — RL (rear-left)

**Цепочка преобразований:**
```
T_total = T_base × T_hip_abd × T_thigh_pitch × T_thigh × T_calf_pitch × T_calf × T_foot
```

Где:
- `T_base` — смещение к базе ноги (±body_length/2, ±body_width/2, -l1)
- `T_hip_abd` — вращение hip вокруг Z
- `T_thigh_pitch` — вращение thigh вокруг Y
- `T_thigh` — смещение на l2 по X
- `T_calf_pitch` — вращение calf вокруг Y
- `T_calf` — смещение на l3 по X
- `T_foot` — смещение на l4 по X

#### `forward_kinematics_all_legs(joint_angles)`
Вычисляет позиции всех 4 стоп.

**Вход:** 12 углов `[FR_hip, FR_thigh, FR_calf, FL_hip, FL_thigh, FL_calf, RR_hip, RR_thigh, RR_calf, RL_hip, RL_thigh, RL_calf]`

**Выход:** 4 позиции `[(x,y,z)_FR, (x,y,z)_FL, (x,y,z)_RR, (x,y,z)_RL]`

## Цепочка кинематики ноги

```
      hip (θ1, Z-rotation)
        │
        ├── base (body corner)
        │
      thigh (θ2, Y-rotation) ── l2 ──►
        │
      calf (θ3, Y-rotation) ── l3 ──►
        │
      foot ── l4 ──► [end effector]
```

## Использование

Основной потребитель — [[Одометрия по контакту стоп]] (QuadrupedOdometryNode), который использует FK для определения позиций стоп относительно корпуса.
