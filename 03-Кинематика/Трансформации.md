# Трансформации

## Файл
`src/quadropted_controller/scripts/RoboticsUtilities/Transformations.py`

## Описание

Утилиты для создания матриц поворота и однородных преобразований. Используются в [[Прямая кинематика|FK]], [[Обратная кинематика|IK]] и [[Trot Gait Controller]].

## Функции

### `rotx(alpha)`
Матрица поворота 3×3 вокруг оси X:
```
[1,  0,       0      ]
[0,  cos(α), -sin(α)]
[0,  sin(α),  cos(α)]
```

### `roty(beta)`
Матрица поворота 3×3 вокруг оси Y:
```
[cos(β),  0,  sin(β)]
[0,       1,  0     ]
[-sin(β), 0,  cos(β)]
```

### `rotz(gamma)`
Матрица поворота 3×3 вокруг оси Z:
```
[cos(γ), -sin(γ), 0]
[sin(γ),  cos(γ), 0]
[0,       0,      1]
```

### `rotxyz(alpha, beta, gamma)`
Комбинированная матрица поворота 3×3: `Rx(α) × Ry(β) × Rz(γ)`

### `homog_transxyz(dx, dy, dz)`
Однородная матрица трансляции 4×4:
```
[1, 0, 0, dx]
[0, 1, 0, dy]
[0, 0, 1, dz]
[0, 0, 0, 1 ]
```

### `homog_transform(dx, dy, dz, alpha, beta, gamma)`
Однородная матрица 4×4 (вращение + трансляция): `T × R`

### `homog_transform_inverse(matrix)`
Обратное однородное преобразование. Для матрицы `[R | d; 0 | 1]`:
```
inverse = [R^T | -R^T × d]
          [0   | 1       ]
```

## Использование

| Компонент | Используемые функции |
|---|---|
| [[Прямая кинематика]] | `homog_transform` |
| [[Обратная кинематика]] | `homog_transform`, `homog_transform_inverse` |
| [[Trot Gait Controller]] | `rotxyz`, `rotz` |
| [[Rest Controller]] | `rotxyz` |
