# Одометрия по контакту стоп

## Файл
`src/quadropted_controller/scripts/QuadrupedOdometryNode.py`

## Описание

Узел `DogOdometry` — оценка положения робота по данным о контакте стоп с землёй и прямой кинематике. Альтернатива колёсным энкодерам для шагающих роботов.

## Алгоритм одометрии

### Принцип работы

1. **FK** — по 12 углам сочленений вычисляются позиции всех 4 стоп
2. **Contact detection** — определяются стопы на земле (из `foot_contact`)
3. **Delta tracking** — для стоп на земле отслеживается смещение
4. **Averaging** — смещения усредняются скользящим окном (window=14)
5. **Integration** — усреднённые смещения интегрируются в глобальную позицию

### Формула обновления

```python
# Для каждой стопы на земле:
delta_x = foot_x - prev_foot_x
delta_y = foot_y - prev_foot_y

# Смещение робота противоположно движению стоп
delta_x_total += delta_x
delta_y_total += -delta_y

# Усреднение
avg_delta_x = mean(delta_x_queue)  # window=14
avg_delta_y = mean(delta_y_queue)

# Интеграция с учётом курса
x += avg_delta_x * cos(theta) - avg_delta_y * sin(theta)
y += avg_delta_x * sin(theta) + avg_delta_y * cos(theta)
```

### Fallback режим

Если ни одна стопа не на земле (робот в воздухе):
```python
# Используем команду скорости
delta_x = linear_velocity_x * dt
delta_y = linear_velocity_y * dt
```

### Курс (theta)

Устанавливается **только** из IMU (yaw из кватерниона). Не интегрируется из угловой скорости.

## Параметры фильтра

| Параметр | Значение | Описание |
|---|---|---|
| `filter_window_size` | 14 | Размер окна скользящего среднего |
| `VELOCITY_COEFFICIENT` | 11.66 | Коэффициент коррекции скорости |
| `contact_count_factor` | 0.65 | Вес каждой контактирующей стопы |

## Максимальные скорости

| Ось | Максимум |
|---|---|
| Linear X | 0.035 м/с |
| Linear Y | 0.012 м/с |
| Angular | 1.0 рад/с |
