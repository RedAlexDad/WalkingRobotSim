# Одометрия по контакту стоп

## Файл
`src/quadropted_controller/scripts/QuadrupedOdometryNode.py`

## Класс `DogOdometry`

Узел оценки положения робота по данным о контакте стоп с землёй и прямой кинематике. Публикует `nav_msgs/Odometry`, TF transform `odom -> base` и маркеры стоп для RViz.

## Алгоритм одометрии

### Принцип работы

1. **FK** -- по 12 углам сочленений вычисляются позиции всех 4 стоп
2. **Contact detection** -- определяются стопы на земле (из `foot_contact`)
3. **Delta tracking** -- для стоп на земле отслеживается смещение относительно предыдущей позиции
4. **Averaging** -- смещения усредняются скользящим окном (window=14)
5. **Integration** -- усреднённые смещения интегрируются в глобальную позицию с учётом курса от IMU

### Формула обновления

```python
# Для каждой стопы на земле:
foot_rel_x, foot_rel_y = foot_positions[i][0], foot_positions[i][1]
delta_x = foot_rel_x - prev_foot_positions[i][0]
delta_y = foot_rel_y - prev_foot_positions[i][1]

delta_x_total += delta_x
delta_y_total += -delta_y  # инверсия Y
contact_count += 0.65  # вес каждой контактирующей стопы

# Усреднение
delta_x = delta_x_total / contact_count
delta_y = delta_y_total / contact_count

self.delta_x_queue.append(delta_x)
self.delta_y_queue.append(delta_y)

avg_delta_x = sum(self.delta_x_queue) / len(self.delta_x_queue)
avg_delta_y = sum(self.delta_y_queue) / len(self.delta_y_queue)

# Интеграция с учётом курса
self.x += avg_delta_x * cos(theta) - avg_delta_y * sin(theta)
self.y += avg_delta_x * sin(theta) + avg_delta_y * cos(theta)
```

### Fallback режим

Если ни одна стопа не на земле (робот в воздухе):
```python
# Используем команду скорости
delta_x = linear_velocity_x * dt
delta_y = linear_velocity_y * dt
```

### Курс (theta)

Устанавливается **только** из IMU (yaw из кватерниона). Не интегрируется из угловой скорости.

```python
# imu_callback:
(roll, pitch, yaw) = euler_from_quaternion(orientation_list)
self.theta = yaw
self.imu_angular_velocity = -msg.angular_velocity.z
```

## Максимальные скорости

| Ось | Максимум |
|---|---|
| Linear X | 0.035 м/с |
| Linear Y | 0.012 м/с |
| Angular | 1.0 рад/с |

## Визуализация маркеров

Метод `publish_markers()` создаёт 4 сферы (Marker.SPHERE) в RViz:
- Размер: 0.05 м
- Цвет: красный (r=1.0, g=0.0, b=0.0, a=1.0)
- Frame: base_frame_id
- Namespace: "foot_markers"
