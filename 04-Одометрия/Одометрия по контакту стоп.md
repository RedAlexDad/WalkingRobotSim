# Одометрия по контакту стоп

## Файл
`src/quadropted_controller/scripts/QuadrupedOdometryNode.py` (472 строки)

## Описание

Узел `DogOdometry` — оценка положения робота по данным о контакте стоп с землёй и прямой кинематике. Альтернатива колёсным энкодерам для шагающих роботов. Вся логика в одном файле (монолитный класс `DogOdometry`).

## Алгоритм одометрии

### Принцип работы

1. **FK** — по 12 углам сочленений вычисляются позиции всех 4 стоп (`KinematicsCalculator`)
2. **Contact detection** — определяются стопы на земле (из `foot_contact`)
3. **Delta tracking** — для стоп на земле отслеживается смещение
4. **Averaging** — смещения усредняются скользящим окном (`OdometryFilter`, window=14)
5. **Integration** — усреднённые смещения интегрируются в глобальную позицию

### Формула обновления

```python
# Для каждой стопы на земле:
delta_x = foot_x - prev_foot_x
delta_y = foot_y - prev_foot_y

# Смещение робота противоположно движению стоп
delta_x_total += delta_x
delta_y_total += -delta_y
contact_count += 0.65  # Вес каждой контактирующей стопы

# Усреднение через фильтр скользящего среднего (window=14)
avg_delta_x = filter.get_filtered_delta()[0]
avg_delta_y = filter.get_filtered_delta()[1]

# Интеграция с учётом курса (2D rotation matrix)
# ВАЖНО: НЕ применять normalize_angle() к cos/sin!
x += avg_delta_x * cos(theta) - avg_delta_y * sin(theta)
y += avg_delta_x * sin(theta) + avg_delta_y * cos(theta)
```

### Математика преобразования координат

Позиции стоп вычисляются в системе координат тела (base_link). Когда робот двигается, стопы на земле остаются неподвижными относительно мира, но их позиция в системе координат тела меняется.

**Ключевая формула** — поворот смещения из системы тела в систему мира:

$$
\begin{bmatrix} \Delta x_{world} \\ \Delta y_{world} \end{bmatrix} = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix} \begin{bmatrix} \Delta x_{body} \\ \Delta y_{body} \end{bmatrix}
$$

Где:
- $\theta$ — курс робота (yaw из IMU)
- $\Delta x_{body}, \Delta y_{body}$ — усреднённое смещение стоп в системе тела
- $\Delta x_{world}, \Delta y_{world}$ — смещение в глобальной системе координат

**Критическая ошибка**: `normalize_angle()` применяется ТОЛЬКО к углам, НЕ к результатам `cos/sin`. Функция `normalize_angle(angle) = atan2(sin(angle), cos(angle))` ожидает угол в радианах, а `cos(theta)` возвращает значение в диапазоне [-1, 1].

### Fallback режим

Если ни одна стопа не на земле (робот в воздухе):
```python
# Используем команду скорости
delta_x = linear_velocity_x * dt
delta_y = linear_velocity_y * dt
```

### Курс (theta)

Устанавливается **только** из IMU (yaw из кватерниона). Не интегрируется из угловой скорости.

## Максимальные скорости

| Ось | Максимум |
|---|---|
| Linear X | 0.035 м/с |
| Linear Y | 0.012 м/с |
| Angular | 1.0 рад/с |

## IMU данные

Угловая скорость IMU сохраняется как `imu_angular_velocity = -msg.angular_velocity.z` (инвертированный Z) и используется в публикации одометрии.
