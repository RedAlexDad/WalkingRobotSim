# Словарь терминов ROS2

Методичка 01: Базовые термины

---

## A

### Action (Действие)
Асинхронный механизм коммуникации в ROS2 для выполнения длительных задач. Действие позволяет отслеживать прогресс выполнения и при необходимости отменить его.

Пример: Навигация робота из точки A в точку B.

---

## D

### DDS (Data Distribution Service)
Промежуточное ПО для обмена данными в реальном времени. ROS2 использует DDS для связи между узлами.

Простыми словами: "Почтовая служба" ROS2, которая доставляет сообщения между узлами.

---

## G

### Graph (Граф ROS2)
Сеть всех узлов, топиков, сервисов и действий в ROS2-системе.

Пример: Граф показывает, какие узлы связаны между собой и через какие топики.

---

## L

### Launch (Запуск)
Механизм ROS2 для одновременного запуска нескольких узлов с заданными параметрами.

Пример: Один файл запуска может поднять сразу 5 узлов для управления роботом.

---

## M

### Message (Сообщение)
Структура данных, передаваемая через топики.

Примеры:
- Twist -- команда скорости
- JointState -- состояние сочленений
- Odometry -- информация о положении

---

## N

### Node (Узел)
Базовая единица вычислений в ROS2. Программа, выполняющая одну задачу.

Аналогия: Повар на кухне, который готовит только одно блюдо.

Примеры:
- robot_controller_node -- управляет роботом
- camera_node -- работает с камерой

---

## P

### Package (Пакет)
Базовая единица организации кода в ROS2. Содержит узлы, конфигурации, зависимости.

Аналогия: Коробка с инструментами для конкретной задачи.

### Parameter (Параметр)
Настраиваемое значение для узла.

Пример: Скорость робота, коэффициент усиления ПИД-регулятора.

### Publisher (Издатель)
Узел, который отправляет сообщения в топик.

Аналогия: Телевизионный канал, который вещает программу.

---

## Q

### QoS (Quality of Service)
Настройки качества обслуживания в ROS2. Определяют надёжность доставки сообщений.

Примеры профилей:
- Reliable -- гарантированная доставка
- Best Effort -- доставка без гарантий (быстрее)

---

## R

### RMW (ROS Middleware)
Уровень абстракции ROS2 для работы с разными DDS-реализациями.

Примеры: rmw_cyclonedds_cpp, rmw_fastrtps_cpp

### ROS2 (Robot Operating System 2)
Набор библиотек и инструментов для создания робототехнических приложений.

Важно: Это НЕ операционная система!

---

## S

### Service (Сервис)
Синхронный механизм коммуникации по схеме "запрос-ответ".

Аналогия: Звонок в службу поддержки -- вы задаёте вопрос, получаете ответ.

Пример: Сервис /robot/set_mode -- отправляете режим, получаете подтверждение.

### Subscriber (Подписчик)
Узел, который получает сообщения из топика.

Аналогия: Зритель, который смотрит телевизионный канал.

---

## T

### Topic (Топик)
Именованный канал для обмена сообщениями между узлами.

Аналогия: Телевизионный канал -- кто подписался, тот и получает контент.

Примеры:
- /cmd_vel -- команды скорости
- /odom -- одометрия
- /joint_states -- состояния сочленений

### Type (Тип сообщения)
Структура данных сообщения.

Пример: geometry_msgs/msg/Twist имеет поля linear и angular.

---

## U

### URDF (Unified Robot Description Format)
XML-формат для описания роботов (сочленения, ссылки, инерция).

Пример: Описание робота Unitree Go2 в файле go2_description.urdf.xacro.

---

## W

### Workspace (Рабочая область)
Папка с исходным кодом ROS2-проектов.

Структура:
```
ws/
  src/          Исходный код
  build/        Файлы сборки
  install/      Установленные пакеты
  logs/         Логи
```
