## 1. Что такое ROS2

### 1.1. Простое определение

ROS2 -- это как "нервная система" для робота.

Представьте себе человеческое тело:
- Мозг принимает решения
- Нервы передают сигналы
- Мышцы выполняют действия

В роботе ROS2 выполняет роль нервной системы -- он помогает разным частям робота общаться друг с другом.

### 1.2. Техническое определение

ROS2 (Robot Operating System 2) -- это набор программных инструментов для создания робототехнических приложений.

Важно: ROS2 -- это НЕ операционная система вроде Windows или Linux. Это middleware -- промежуточное ПО, которое работает поверх операционной системы.

```
+-------------------------------------+
|             Ваше приложение         |
+-------------------------------------+
|           ROS2 (middleware)         |
+-------------------------------------+
|      Операционная система (OS)      |
|         (Ubuntu, Windows, etc.)     |
+-------------------------------------+
|            Железо робота            |
|         (моторы, сенсоры, etc.)     |
+-------------------------------------+
```

### 1.3. Почему "2"?

ROS2 -- это вторая версия ROS. Первая версия (ROS1) была создана в 2007 году. ROS2 вышел в 2016 году с улучшениями:

ROS1:
- Работал только на Linux
- Нестабильная связь
- Нет реального времени
- Один центральный сервер

ROS2:
- Работает на Linux, Windows, macOS
- Надёжная связь
- Поддержка реального времени
- Распределённая система

## 2. Зачем нужен ROS2

### 2.1. Проблема без ROS2

Представьте, что вы строите робота с 4 моторами, 1 камерой, 1 датчиком расстояния и 1 кнопкой.

Без ROS2 вам нужно:
1. Написать код для каждого мотора отдельно
2. Написать код для камеры
3. Написать код для датчика расстояния
4. Придумать, как всё это связать вместе
5. Придумать, как передавать данные между компонентами

Это как строить дом без чертежей -- каждый рабочий делает что хочет.

### 2.2. Решение с ROS2

С ROS2 вы:
1. Создаёте узел для каждого мотора
2. Создаёте узел для камеры
3. Создаёте узел для датчика
4. ROS2 сам связывает всё через топики

Это как строить дом по чертежам -- у каждого рабочего есть инструкция, как общаться с другими.

### 2.3. Преимущества ROS2

- Модульность -- каждый компонент отдельный блок
- Переиспользование -- готовые компоненты можно использовать в других проектах
- Независимость от языка -- можно писать на C++, Python, Java
- Экосистема -- тысячи готовых пакетов
- Сообщество -- миллионы разработчиков по всему миру

## 3. Основные концепции на примерах

### 3.1. Узел (Node)

Узел -- это программа, которая выполняет одну задачу.

Аналогия из жизни:
- Повар на кухне -- узел "приготовление еды"
- Курьер -- узел "доставка"
- Оператор колл-центра -- узел "обработка звонков"

Примеры узлов в роботе:
- robot_controller_node -- управление роботом
- camera_node -- работа с камерой
- sensor_node -- чтение датчиков
- motor_node -- управление мотором

### 3.2. Топик (Topic)

Топик -- это канал связи между узлами.

Аналогия из жизни:
- Телевизионный канал -- кто подписался, тот и смотрит
- Газета -- кто подписался, тот и получает
- Радиостанция -- кто настроился, тот и слушает

Как работает:
```
+--------------+    /camera/image    +--------------+
|   Camera     | ------------------> |   Viewer     |
| (Publisher)  |                     | (Subscriber) |
+--------------+                     +--------------+
```

### 3.3. Сообщение (Message)

Сообщение -- это данные, которые передаются через топик.

Примеры сообщений:
- /camera/image -- картинка с камеры
- /cmd_vel -- команда скорости (вперёд, назад, повернуть)
- /odom -- информация о положении робота
- /battery_level -- уровень заряда батареи

### 3.4. Публикация и подписка

Publisher (Издатель) -- узел, который отправляет сообщения.
Subscriber (Подписчик) -- узел, который получает сообщения.

Аналогия:
- YouTube-канал -- publisher
- Зритель -- subscriber

### 3.5. Граф ROS2

Граф ROS2 -- это вся сеть узлов и топиков в системе.

Пример графа для нашего робота:
```
                    /cmd_vel
     +----------+  ----------+
     | Keyboard |            v
     |          |     +--------------+
     +----------+     |  Velocity    |
                      |   Handler    |
                      +------+-------+
                             | /robot_velocity
                             v
     +----------+     +--------------+
     |   Mode   |---->|    Robot     |
     |  Command |     |  Controller  |
     +----------+     +------+-------+
                             | /joint_commands
                             v
                      +--------------+
                      |    Gazebo    |
                      |  Simulation  |
                      +--------------+
```

## 4. Терминал для новичков

### 4.1. Что такое терминал

Терминал -- это текстовый интерфейс для управления компьютером.

Аналогия:
- Графический интерфейс -- как меню в ресторане (красиво, с картинками)
- Терминал -- как заказать по телефону (быстро, но нужно знать, что просить)

### 4.2. Базовые команды

- pwd -- показать текущую папку
- ls -- показать файлы в папке
- cd -- перейти в папку
- cd .. -- перейти на папку вверх
- mkdir -- создать папку
- cat -- показать содержимое файла

### 4.3. Практика

Откройте терминал и попробуйте:

```bash
# 1. Узнать, где вы находитесь
pwd

# 2. Посмотреть, какие файлы есть
ls

# 3. Перейти в домашнюю папку
cd ~

# 4. Создать новую папку
mkdir test_folder

# 5. Перейти в неё
cd test_folder

# 6. Вернуться назад
cd ..

# 7. Удалить папку
rmdir test_folder
```

### 4.4. Команды ROS2

- ros2 node list -- показать все узлы
- ros2 topic list -- показать все топики
- ros2 topic echo <topic> -- подписаться на топик
- ros2 topic pub <topic> <type> <data> -- опубликовать сообщение
- ros2 run <package> <node> -- запустить узел

## 6. FAQ

### ROS2 бесплатный?

Да. ROS2 полностью бесплатный и имеет открытый исходный код.

### Нужен ли мне реальный робот для изучения ROS2?

Нет. Вы можете изучать ROS2 с помощью симуляторов (например, Gazebo в нашем проекте).

### Какой язык программирования нужен?

Python или C++. Python проще для начала, C++ быстрее для production.

### Сколько времени нужно на изучение ROS2?

Зависит от вас:
- Базовые концепции -- 1-2 недели
- Уверенная работа -- 1-2 месяца
- Продвинутый уровень -- 6+ месяцев

### ROS2 работает на Windows?

Да. ROS2 работает на Windows, Linux и macOS.

### Что такое дистрибутив ROS2?

Дистрибутив -- это версия ROS2. Наш проект использует ROS2 Jazzy (2024).
