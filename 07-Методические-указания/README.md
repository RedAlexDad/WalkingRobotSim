# Методические указания по ROS2 и WalkingRobotSim

Добро пожаловать в учебный курс по ROS2 на примере симулятора шагающего робота **WalkingRobotSim** (Unitree Go2).

Этот курс поможет вам освоить ROS2 с нуля — от базовых концепций до работы с реальным проектом симуляции четырехногого робота.

---

## Структура курса

Курс разделен на 5 модулей. Рекомендуется проходить их последовательно:

### 01-basics — Основы ROS2

Изучение базовых концепций ROS2: узлы, топики, сообщения, сервисы. Команды терминала и базовые команды ROS2.

- [README](01-basics/README.md) — введение в ROS2, основные понятия
- [Глоссарий](01-basics/glossary.md) — определения терминов
- [Шпаргалка команд](01-basics/commands_cheatsheet.md) — справочник команд ROS2
- [Тест](01-basics/quiz.md) — проверка знаний

### 02-topics — Топики и сообщения

Работа с топиками ROS2: подписка, публикация, типы сообщений. Практика взаимодействия узлов.

- [README](02-topics/README.md) — что такое топики, как с ними работать
- [Шпаргалка](02-topics/cheatsheet.md) — команды работы с топиками
- [Тест](02-topics/quiz.md) — проверка знаний по топикам

### 03-docker — Docker для ROS2

Контейнеризация ROS2-проектов. Сборка, запуск и управление контейнерами WalkingRobotSim.

- [README](03-docker/README.md) — зачем Docker, как работает проект
- [Шпаргалка](03-docker/cheatsheet.md) — команды Docker
- [Тест](03-docker/quiz.md) — проверка знаний по Docker

### 04-project-arch — Архитектура проекта

Структура проекта WalkingRobotSim, пакеты, режимы робота, потоки данных.

- [README](04-project-arch/README.md) — архитектура проекта, режимы робота
- [Шпаргалка](04-project-arch/cheatsheet.md) — справочник по проекту
- [Тест](04-project-arch/quiz.md) — проверка знаний по архитектуре

### 05-exercises — Практические задания

Пошаговые упражнения для закрепления материала: от первого запуска до создания собственного узла.

- [README](05-exercises/README.md) — 6 практических упражнений
- [Чеклист](05-exercises/checklist.md) — список для проверки выполнения

## Рекомендуемые пути обучения

### Для начинающих (4-6 недель)

1. Неделя 1: [01-basics](01-basics/README.md) — основы ROS2
2. Неделя 2: [02-topics](02-topics/README.md) — топики и сообщения
3. Неделя 3: [03-docker](03-docker/README.md) — Docker
4. Неделя 4-5: [04-project-arch](04-project-arch/README.md) — архитектура проекта
5. Неделя 5-6: [05-exercises](05-exercises/README.md) — практические задания

### Для знакомых с ROS (2-3 недели)

1. Неделя 1: Беглый просмотр [01-basics](01-basics/README.md) и [02-topics](02-topics/README.md)
2. Неделя 2: [03-docker](03-docker/README.md) и [04-project-arch](04-project-arch/README.md)
3. Неделя 3: [05-exercises](05-exercises/README.md) — практика

### Для опытных (1 неделя)

1. День 1-2: [03-docker](03-docker/README.md) — запуск проекта
2. День 3-4: [04-project-arch](04-project-arch/README.md) — изучение архитектуры
3. День 5-7: [05-exercises](05-exercises/README.md) — упражнения
