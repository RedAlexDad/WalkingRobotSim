## Результаты поиска

Перерыты: arxiv, IEEE Xplore, Springer, MDPI, CNKI, BAAI (智源社区), 3D视觉工坊.

## 5 ближайших работ

### 1. PanoMMOcc / VoxelHound (Hunan University, 2026)

- **Ссылка:** https://arxiv.org/abs/2603.13108
- **Сенсор:** Камеры (panoramic RGB + глубина)
- **Задача:** Panoramic multimodal semantic occupancy prediction
- **Платформа:** Четвероногий робот
- **Ключевое:** есть модуль **Vertical Jitter Compensation (VJC)** — компенсация тряски корпуса (pitch/roll) при движении
- **Метрика:** mIoU
- **Отличие от нас:** камеры, не LiDAR; компенсируют тряску, а не измеряют её влияние; occupancy, не сегментация

### 2. OneOcc (Zhejiang University, CVPR 2026)

- **Ссылка:** https://arxiv.org/abs/2511.03571
- **Сенсор:** Камера (single panoramic RGB)
- **Задача:** Semantic occupancy prediction для legged/humanoid robots
- **Платформа:** Четвероногий робот
- **Ключевое:** есть **Gait Displacement Compensation (GDC)** — компенсация смещения от походки
- **Метрика:** mIoU
- **Отличие от нас:** камеры, не LiDAR; компенсируют, не измеряют влияние; occupancy, не сегментация

### 3. Online Object-Level Semantic Mapping (IIT, I-RIM 2025)

- **Ссылка:** https://arxiv.org/abs/2510.18776
- **Сенсор:** Камера + range geometry
- **Задача:** Online semantic object mapping для четвероногих роботов
- **Платформа:** Четвероногий робот (реальные indoor-тесты)
- **Метрика:** стабильность объектов across viewpoint changes
- **Отличие от нас:** камеры, не LiDAR; object-level mapping, не point-level сегментация; не про влияние походки

### 4. TARL (University of Bonn, CVPR 2023)

- **Ссылка:** https://openaccess.thecvf.com/content/CVPR2023/html/Nunes_Temporal_Consistent_3D_LiDAR_Representation_Learning_for_Semantic_Perception_in_CVPR_2023_paper.html
- **GitHub:** https://github.com/PRBonn/TARL
- **Сенсор:** LiDAR (Velodyne 64)
- **Задача:** Temporal consistent 3D LiDAR representation learning
- **Платформа:** **Автомобиль** (SemanticKITTI)
- **Ключевое:** «temporal consistent» — это learning objective (регуляризатор), а не метрика оценки
- **Метрика:** mIoU
- **Отличие от нас:** автомобили, не четвероногие; temporal consistency как цель обучения, не как метрика оценки

### 5. TFNet / TASeg (CVPR 2024)

- **TFNet:** https://arxiv.org/abs/2309.07849
- **TASeg:** https://arxiv.org/abs/2407.09751
- **Сенсор:** LiDAR
- **Задача:** Temporal cues / temporal aggregation для LiDAR сегментации
- **Платформа:** **Автомобиль** (KITTI, nuScenes)
- **Метрика:** mIoU
- **Отличие от нас:** автомобили, не четвероногие; temporal для улучшения точности, не для оценки стабильности

## Вывод

**На пересечении «четвероногий робот + LiDAR семантическая сегментация + влияние походки на стабильность» — пусто.**

- Работы по четвероногим + LiDAR: навигация, SLAM, одометрия (LLIO 2025, IEEE 2025)
- Работы по LiDAR семантической сегментации: автомобили (SemanticKITTI, nuScenes)
- Работы по семантике для четвероногих: камеры (PanoMMOcc, OneOcc)
- Работы по temporal cues для LiDAR: автомобили (TARL, TFNet, TASeg)

**Наша метрика temporal consistency** (доля точек, сохраняющих метку в соседних кадрах) в привязке к режиму походки — **никто не измерял**.
