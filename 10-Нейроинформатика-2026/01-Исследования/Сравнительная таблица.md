# Сравнительная таблица моделей

## Критерии выбора

| Критерий | Вес | Описание |
|----------|-----|----------|
| Наличие предобученных весов | Высокий | Не нужно обучать с нуля |
| Совместимость с Gazebo LiDAR | Высокий | 2D range image vs 3D point cloud |
| Простота интеграции | Средний | Python API, зависимости |
| Качество (mIoU на SemanticKITTI) | Средний | Точность сегментации |
| Скорость инференса | Низкий | Для статьи не критично |

## Сравнение

| Модель | Предобученные веса | Формат входа | mIoU (SemanticKITTI) | Скорость | Интеграция |
|--------|-------------------|--------------|---------------------|----------|------------|
| **RangeNet++** | ✅ SemanticKITTI | Range image (2D) | ~54.5% | ~30 FPS | Python/C++ |
| **SqueezeSegV3** | ✅ SemanticKITTI | Range image (2D) | ~60.2% | ~50 FPS | Python/PyTorch |
| **RandLA-Net** | ✅ SemanticKITTI | Point cloud (3D) | ~68.5% | ~10 FPS | Python/TF |
| **Cylinder3D** | ✅ SemanticKITTI | Cylindrical voxels | ~72.3% | ~15 FPS | Python/PyTorch |
| **PointNet++** | ❌ | Point cloud (3D) | ~40% | ~5 FPS | Python/TF |

## Итоговая рекомендация

### Основной выбор: **SqueezeSegV3**

- Лучший баланс точности и скорости
- PyTorch — удобно для экспериментов
- Range image —可以直接 из Gazebo LiDAR
- mIoU ~60% — достаточно для демонстрации

### Запасной вариант: **RangeNet++**

- Более зрелый проект
- Есть готовый ROS-интерфейс
- Если SqueezeSegV3 окажется сложным в настройке

## Что нужно для эксперимента

1. **Данные:** синтетические LiDAR сканы из Gazebo (warehouse/cafe/residential миры)
2. **Модель:** предобученная на SemanticKITTI
3. **Метрики:** mIoU, per-class IoU, inference time
4. **Визуализация:** цветная сегментация на range image + 3D view
