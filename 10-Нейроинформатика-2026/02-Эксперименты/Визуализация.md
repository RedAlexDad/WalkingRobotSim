### Рис. 2 — Три режима робота

Три скриншота из Gazebo:
- (а) REST — робот лежит
- (б) STAND — робот стоит
- (в) TROT — робот идёт

### Рис. 3 — Range image с семантической сегментацией

Range image (левая половина) + предсказанные метки (правая половина, цветовая кодировка).

Для каждого режима: REST, STAND, TROT.

### Рис. 4 — Temporal consistency по времени

Line chart:
- X: время (секунды)
- Y: consistency (0..1)
- 3 линии: REST (зелёная), STAND (жёлтая), TROT (красная)

### Рис. 5 — Средняя consistency по режимам

Bar chart с error bars:
- X: режим (REST, STAND, TROT)
- Y: средняя consistency
- Error bars: std deviation

### Рис. 6 — Variance map

Тепловая карта для каждого режима:
- Синий = стабильные предсказания (variance = 1)
- Красный = нестабильные (variance > 3)

## Код для визуализации

```python
import matplotlib
matplotlib.use('Agg')  # без GUI
import matplotlib.pyplot as plt
import numpy as np

# Рис. 4 — Consistency по времени
def plot_consistency_over_time(rest_tc, stand_tc, trot_tc):
    fig, ax = plt.subplots(figsize=(10, 6))

    ax.plot(rest_tc, label='REST', linewidth=2)
    ax.plot(stand_tc, label='STAND', linewidth=2)
    ax.plot(trot_tc, label='TROT', linewidth=2)

    ax.set_xlabel('Время (с)')
    ax.set_ylabel('Temporal Consistency')
    ax.legend()
    ax.grid(True, alpha=0.3)

    # Чёрно-белый стиль для статьи
    ax.set_facecolor('white')
    fig.patch.set_facecolor('white')

    plt.savefig('fig4_consistency_time.png', dpi=300,
                bbox_inches='tight', facecolor='white')
    plt.close()

# Рис. 5 — Bar chart
def plot_consistency_bar(means, stds):
    fig, ax = plt.subplots(figsize=(6, 4))

    modes = ['REST', 'STAND', 'TROT']
    x = np.arange(len(modes))

    ax.bar(x, means, yerr=stds, capsize=5,
           color=['white', 'lightgray', 'gray'],
           edgecolor='black', hatch=['', '///', 'xxx'])

    ax.set_xticks(x)
    ax.set_xticklabels(modes)
    ax.set_ylabel('Temporal Consistency')
    ax.set_ylim(0, 1)

    plt.savefig('fig5_consistency_bar.png', dpi=300,
                bbox_inches='tight', facecolor='white')
    plt.close()

# Рис. 6 — Variance map
def plot_variance_map(variance_maps):
    fig, axes = plt.subplots(1, 3, figsize=(12, 4))

    for i, (mode, var_map) in enumerate(zip(['REST', 'STAND', 'TROT'], variance_maps)):
        im = axes[i].imshow(var_map, cmap='hot', vmin=1, vmax=5)
        axes[i].set_title(mode)
        axes[i].axis('off')
        plt.colorbar(im, ax=axes[i], fraction=0.046)

    plt.savefig('fig6_variance_maps.png', dpi=300,
                bbox_inches='tight', facecolor='white')
    plt.close()
```
