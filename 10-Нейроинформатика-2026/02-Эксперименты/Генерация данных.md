# Генерация синтетических LiDAR данных

## Цель

Создать набор синтетических LiDAR данных из симуляции Gazebo для тестирования модели семантической сегментации.

## Подход

### 1. Использование существующих миров

Проект уже содержит миры:
- `warehouse` — склад
- `residential` — жилой район
- `cafe` — кафе

### 2. Запись данных

```bash
# Запуск симуляции с записью LiDAR данных
ros2 bag record -O lidar_data /robot1/scan
```

### 3. Конвертация в формат модели

LiDAR данные из Gazebo (`sensor_msgs/LaserScan`) → range image (2D массив дальностей).

#### Формат RangeNet++ / SqueezeSeg

```
Range image: H x W x 3 (depth, x, y) или H x W x 4 (depth, x, y, z)
H = 64 (каналы LiDAR)
W = 1024 (горизонтальное разрешение)
```

### 4. Генерация ground truth

Для синтетических данных ground truth можно получить:
- Из Gazebo (сегментация по моделям в мире)
- Ручная разметка (не рекомендуется — долго)
- Автоматическая проекция 3D моделей на range image
