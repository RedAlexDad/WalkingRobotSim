# Запись LiDAR данных при разных режимах

## Цель

Записать LiDAR сканы при трёх режимах работы робота: REST, STAND, TROT.

## Подход

### 1. Запуск симуляции

```bash
./manage.sh up
```

### 2. Запись данных для каждого режима

#### REST (робот лежит)

```bash
# Робот по умолчанию в REST
ros2 bag record -O lidar_rest /robot1/scan /robot1/imu
# Ждём 60 секунд
ros2 bag stop
```

#### STAND (робот стоит)

```bash
# Переключение в STAND
ros2 topic pub /robot1/mode_command quadropted_msgs/msg/RobotModeCommand "{robot_id: 1, mode: 1}"
# Запись
ros2 bag record -O lidar_stand /robot1/scan /robot1/imu
# Ждём 60 секунд
```

#### TROT (робот идёт)

```bash
# Переключение в TROT
ros2 topic pub /robot1/mode_command quadropted_msgs/msg/RobotModeCommand "{robot_id: 1, mode: 2}"
# Отправляем команду движения
ros2 topic pub /robot1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.02}, angular: {z: 0.0}}"
# Запись
ros2 bag record -O lidar_trot /robot1/scan /robot1/imu
# Ждём 120 секунд (робот должен пройти по миру)
```

### 3. Проверка данных

```bash
ros2 bag info lidar_rest
ros2 bag info lidar_stand
ros2 bag info lidar_trot
```

## Ожидаемый объём

| Режим | Длительность | Частота LiDAR | Ожидаемое кол-во сканов |
|-------|-------------|---------------|------------------------|
| REST | 60 сек | 10 Гц | ~600 |
| STAND | 60 сек | 10 Гц | ~600 |
| TROT | 120 сек | 10 Гц | ~1200 |

## Что записываем

- `/robot1/scan` — LiDAR данные (sensor_msgs/LaserScan)
- `/robot1/imu` — данные IMU для анализа тряски (sensor_msgs/Imu)
