# Инференс и метрики: Temporal Consistency

## Подход

**НЕ нужен ground truth.** Измеряем стабильность предсказаний во времени.

## Temporal Consistency

**Идея:** если сцена не меняется (робот стоит или медленно движется), то семантические метки соседних кадров должны совпадать.

```python
def temporal_consistency(predictions, threshold=0.9):
    """
    predictions: list of N предсказаний (каждое — H x W массив меток)
    threshold: порог для "похожих" кадров (расстояние робота)

    Returns: consistency score (0..1)
    """
    matching = 0
    total = 0

    for i in range(1, len(predictions)):
        pred_prev = predictions[i - 1]
        pred_curr = predictions[i]

        # Сколько точек сохранили ту же метку
        same = np.sum(pred_prev == pred_curr)
        valid = np.sum((pred_prev != 0) | (pred_curr != 0))  # исключаем «неизвестно»

        matching += same
        total += valid

    return matching / total if total > 0 else 0
```

## Ожидаемые результаты

| Режим | Ожидаемая consistency | Почему |
|-------|----------------------|--------|
| REST | 0.95–0.98 | Робот не двигается, сканы почти идентичны |
| STAND | 0.88–0.93 | Робот качается (PID компенсация), сканы слегка отличаются |
| TROT | 0.70–0.85 | Робот трясётся + движется, сканы сильно отличаются |

## Дополнительная метрика: Variance of Predictions

Для каждой точки (u, v) считаем, сколько **разных** меток она получает за N кадров:

```python
def prediction_variance(predictions):
    """
    predictions: N x H x W массив меток
    Returns: H x W массив — количество уникальных меток для каждой точки
    """
    N, H, W = predictions.shape
    variance = np.zeros((H, W), dtype=int)

    for i in range(H):
        for j in range(W):
            unique_labels = len(np.unique([p[i, j] for p in predictions]))
            variance[i, j] = unique_labels

    return variance
```

Высокая variance = модель «не уверена» в этой точке.
