# Обучение и метрики

## Подход

**Не обучаем с нуля!** Используем предобученную модель (SqueezeSegV3 или RangeNet++) на SemanticKITTI.

### Что делаем:

1. **Инференс** — прогоняем синтетические данные через модель
2. **Оценка** — считаем метрики на данных с ground truth
3. **Анализ** — разбираем ошибки, визуализируем результаты

## Метрики

### Основные

| Метрика | Формула | Описание |
|---------|---------|----------|
| **mIoU** | mean(IoU_class) | Средняя IoU по всем классам |
| **Per-class IoU** | TP / (TP + FP + FN) | IoU для каждого класса |
| **Accuracy** | (TP + TN) / Total | Общая точность |

### Дополнительные

| Метрика | Описание |
|---------|----------|
| **Inference time** | Время обработки одного скана (ms) |
| **FPS** | Сканы в секунду |
| **Memory usage** | Потребление памяти (MB) |

## План эксперимента

| Эксперимент | Описание | Ожидаемый результат |
|-------------|----------|---------------------|
| 1 | Инференс на warehouse | mIoU ~40-50% (domain gap) |
| 2 | Инференс на residential | mIoU ~35-45% |
| 3 | Инференс на cafe | mIoU ~30-40% |
| 4 | Анализ ошибок | Какие классы хуже всего |
| 5 | Визуализация | Карты сегментации |

## Domain gap

**Проблема:** модель обучена на реальных данных (SemanticKITTI), а тестируем на синтетических (Gazebo).

**Ожидаемо:** mIoU будет ниже, чем на оригинальном датасете.

**Для статьи:** это не баг, а фича! Можно обсудить:
- Влияние domain gap на качество
- Потенциал domain adaptation
- Преимущества синтетических данных

## Скрипт оценки

```python
import numpy as np

def compute_iou(pred, gt, num_classes):
    """Вычисление IoU для каждого класса"""
    ious = []
    for cls in range(num_classes):
        tp = np.sum((pred == cls) & (gt == cls))
        fp = np.sum((pred == cls) & (gt != cls))
        fn = np.sum((pred != cls) & (gt == cls))
        iou = tp / (tp + fp + fn) if (tp + fp + fn) > 0 else 0
        ious.append(iou)
    return np.mean(ious), ious  # mIoU, per-class IoU
```
