## НЕЙРОСЕТЕВАЯ ОБРАБОТКА LiDAR ДАННЫХ ДЛЯ СЕМАНТИЧЕСКОГО ПОНИМАНИЯ СЦЕНЫ В ЗАДАЧАХ АВТОНОМНОЙ НАВИГАЦИИ

&nbsp;

Рассматривается применение нейросетевой семантической сегментации данных лидара для обеспечения семантического понимания окружающей среды мобильным роботом. В качестве модели используется архитектура SqueezeSegV3, предобученная на датасете SemanticKITTI. Эксперименты проводятся на синтетических данных, сгенерированных в симуляторе Gazebo для четырёхногого робота Unitree Go2. Оценивается влияние domain gap между реальными и синтетическими данными на качество сегментации. Полученные результаты демонстрируют принципиальную возможность использования предобученных моделей для семантического восприятия в симуляционных средах.

&nbsp;

*Ключевые слова:* семантическая сегментация, лидар, нейронные сети, автономная навигация, мобильные роботы, синтетические данные, domain gap, SqueezeSegV3, Gazebo, ROS 2

### 1. Введение

Автономная навигация мобильных роботов требует не только обнаружения препятствий, но и понимания семантики окружающей среды. Традиционные подходы к навигации, такие как стек Nav2 в ROS 2, оперируют бинарными картами занятости (costmap), где каждая ячейка классифицируется как «свободна» или «занята». Такой подход не позволяет роботу различать типы объектов: стена, человек, столб или лестница воспринимаются одинаково — как непроходимая область.

Семантическая сегментация данных лидара решает эту задачу, присваивая каждой точке облака метку класса. Это открывает возможности для:
- семантически осознанного планирования пути (избегать людей, но допускать проход через траву);
- адаптивного поведения в зависимости от типа окружения;
- улучшения SLAM за счёт семантических признаков.

Однако обучение моделей семантической сегментации требует больших размеченных датасетов, сбор и разметка которых трудоёмки и дороги. Альтернативой является использование синтетических данных из симуляторов, таких как Gazebo, где ground truth доступен автоматически.

Цель данной работы — исследовать применимость нейросетевых моделей семантической сегментации LiDAR, предобученных на реальных данных, к синтетическим данным, генерируемым в симуляторе Gazebo для четырёхногого робота Unitree Go2.

### 2. Обзор литературы

#### 2.1. Методы семантической сегментации LiDAR

Методы семантической сегментации LiDAR можно разделить на три категории.

**Point-based методы** работают непосредственно с облаком точек. PointNet [1] впервые предложил обрабатывать нерегулярные облака точек с помощью многослойных перцептронов. PointNet++ [2] улучшил этот подход, добавив иерархическое извлечение локальных признаков. RandLA-Net [3] использует случайную выборку и локальное агрегирование признаков для эффективной обработки крупных облаков.

**Projection-based методы** проецируют 3D точки на 2D изображение дальностей (range image). SqueezeSeg [4] адаптировал архитектуру SqueezeNet для сегментации range images. SqueezeSegV2 [5] добавил модули контекста, а SqueezeSegV3 [6] — пространственно-адаптивные свёртки. RangeNet++ [7] использует DarkNet-21 с постобработкой через k-NN.

**Voxel-based методы** дискретизируют пространство в воксели. MinkowskiNet [8] применяет разреженные 3D свёртки. Cylinder3D [9] использует цилиндрическое разбиение пространства, достигая state-of-the-art результатов на SemanticKITTI.

#### 2.2. Синтетические данные в робототехнике

Синтетические данные широко используются для обучения и тестирования моделей компьютерного зрения. Однако domain gap — различие между синтетическими и реальными данными — остаётся ключевой проблемой. Для LiDAR этот вопрос изучен меньше, чем для камер.

### 3. Постановка задачи

Входные данные: поток сканов 2D лидара (sensor_msgs/LaserScan в ROS 2), преобразованный в range image размером H × W.

Выходные данные: семантические метки для каждой точки скана из набора классов SemanticKITTI (19 классов).

Требования:
- время инференса ≤ 100 мс на скан (≥ 10 Гц);
- оценка качества по метрике mIoU.

Отличие от традиционной постановки: модель предобучена на реальных данных (SemanticKITTI), а тестируется на синтетических данных из Gazebo. Это позволяет оценить влияние domain gap без дополнительных затрат на обучение.

### 4. Методология

#### 4.1. Архитектура модели

В работе используется модель SqueezeSegV3 [6], основанная на архитектуре encoder-decoder с пространственно-адаптивными свёртками. Encoder извлекает многоуровневые признаки из range image, decoder восстанавливает пространственное разрешение с помощью transpose-свёрток.

*(Здесь будет рисунок 1 — схема архитектуры)*

#### 4.2. Конвертация LiDAR → range image

Данные лидара из Gazebo (sensor_msgs/LaserScan) конвертируются в range image по формулам сферической проекции:

u = round(θ / Δθ)
v = round(φ / Δφ)

где θ — горизонтальный угол, φ — вертикальный угол, Δθ и Δφ — угловые разрешения.

*(Здесь будет рисунок 2 — пример range image)*

#### 4.3. Предобучение

Модель использует предобученные веса на датасете SemanticKITTI [10], содержащем 43 000 сканов с 19 семантическими классами. Датасет собран на базе автомобиля с 64-лучевым лидаром Velodyne HDL-64E.

#### 4.4. Генерация синтетических данных

Синтетические данные генерируются в симуляторе Gazebo с использованием модели четырёхногого робота Unitree Go2. Лидар моделируется с параметрами: 16 лучей, горизонтальное поле зрения 360°, вертикальное ±15°, дальность до 10 м.

Используются три сцены:
- **warehouse** — складское помещение с стеллажами и коробками;
- **residential** — жилой район с зданиями и деревьями;
- **cafe** — помещение кафе со столами и стульями.

*(Здесь будет рисунок 3 — скриншот одной из сцен)*

#### 4.5. Метрики оценки

Основная метрика — mean Intersection over Union (mIoU):

mIoU = (1/N) × Σ(TP_i / (TP_i + FP_i + FN_i))

где N — число классов, TP, FP, FN — истинно положительные, ложно положительные и ложно отрицательные предсказания для класса i.

### 5. Эксперименты

#### 5.1. Описание эксперимента

Для каждой из трёх сцен записывается ~1000 сканов лидара при движении робота. Данные конвертируются в range image и подаются на вход модели SqueezeSegV3. Предсказанные метки сравниваются с ground truth, полученным из семантической информации Gazebo.

### 6. Обсуждение

#### 6.1. Domain gap

Снижение mIoU на синтетических данных по сравнению с реальными объясняется domain gap — различиями в:
- геометрии объектов (упрощённые модели в Gazebo);
- текстуре и отражательной способности поверхностей;
- шуме лидара (модель шума в симуляторе отличается от реального);
- количестве лучей (16 в симуляции vs 64 в SemanticKITTI).

#### 6.2. Влияние на навигацию

Семантическая сегментация позволяет расширить возможности навигации:
- класс «лестница» — робот может идентифицировать перепад высот;
- класс «человек» — повышенная осторожность при планировании;
- класс «дверь» — возможность навигации между помещениями.

#### 6.3. Ограничения и будущая работа

- Использование модели, предобученной на автомобильных данных, для четвероногого робота (другая высота установки лидара);
- Ограниченное число лучей в симуляции;
- Отсутствие fine-tuning на синтетических данных.

В будущем планируется:
- fine-tuning модели на синтетических данных;
- использование domain adaptation методов;
- интеграция семантической информации в стек Nav2.

### 7. Заключение

В работе исследовано применение нейросетевой модели семантической сегментации LiDAR SqueezeSegV3 к синтетическим данным, генерируемым в симуляторе Gazebo для четырёхногого робота Unitree Go2. Полученные результаты показывают принципиальную возможность использования предобученных моделей для семантического восприятия в симуляционных средах, несмотря на domain gap.

Основной результат: демонстрация пайплайна «Gazebo → range image → SqueezeSegV3 → семантические метки» с количественной оценкой качества.

Направления развития: fine-tuning на синтетических данных, domain adaptation, интеграция семантики в навигационный стек.
