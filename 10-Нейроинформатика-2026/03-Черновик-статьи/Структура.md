# Структура статьи

## Требования

- **Объём:** 8–10 страниц (A5, Times New Roman, 10pt)
- **Формат:** Microsoft Word
- **Структура:** Введение → Разделы → Заключение
- **Аннотация:** 5–8 строк
- **Ключевые слова:** до 10 слов
- **Рисунки:** чёрно-белые или полутоновые
- **Формулы:** MS Equation 3.0

## Шаблон

```
И.О. ФАМИЛИЯ (11pt, bold, center)
Организация, город (9pt, center)
email (9pt, center)

[пропуск]

ЗАГОЛОВОК СТАТЬИ (11pt, bold, center)

[пропуск]

Аннотация (10pt, justified)

[пропуск]

Ключевые слова: ... (10pt, italic, justified)

[пропуск]

1. Введение
2. Обзор литературы
3. Постановка задачи
4. Методология
5. Эксперименты
6. Результаты
7. Заключение

[пропуск]

Список литературы (9pt, italic, center)
```

## Предлагаемая структура

### 1. Введение (~1 стр.)

- Проблема автономной навигации мобильных роботов
- Роль LiDAR в восприятии окружения
- Зачем нужна семантическая сегментация (не просто obstacles, а понимание сцены)
- Цель работы: исследовать применение нейросетевой семантической сегментации LiDAR для навигации робособаки

### 2. Обзор литературы (~1.5 стр.)

- Методы семантической сегментации LiDAR:
  - Point-based (PointNet, PointNet++, RandLA-Net)
  - Projection-based (SqueezeSeg, RangeNet++)
  - Voxel-based (MinkowskiNet, Cylinder3D)
- Сравнение подходов (таблица)
- Синтетические данные в робототехнике

### 3. Постановка задачи (~0.5 стр.)

- Вход: LiDAR сканы (sensor_msgs/LaserScan)
- Выход: семантические метки для каждой точки
- Требования: real-time (~10 Hz), точность (mIoU)
- Отличие: работа с синтетическими данными из Gazebo

### 4. Методология (~2 стр.)

- Архитектура выбранной модели (SqueezeSegV3 / RangeNet++)
- Конвертация LiDAR → range image
- Предобучение на SemanticKITTI
- Инференс на синтетических данных
- Метрики оценки (mIoU, per-class IoU)

### 5. Эксперименты (~2 стр.)

- Описание синтетических сцен (warehouse, residential, cafe)
- Процедура генерации данных
- Результаты (таблица mIoU по сценам и классам)
- Анализ ошибок (confusion matrix)
- Визуализация (range image с сегментацией)

### 6. Обсуждение (~1 стр.)

- Domain gap: synthetic vs real
- Влияние на навигацию (как семантика улучшает планирование пути)
- Ограничения и будущая работа

### 7. Заключение (~0.5 стр.)

- Краткие выводы
- Основной результат
- Направления развития
