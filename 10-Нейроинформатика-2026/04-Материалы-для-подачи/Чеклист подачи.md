# Чеклист подачи на Нейроинформатика-2026

## До дедлайна (25 мая 2026)

### Статья

- [ ] Текст статьи написан (8–10 страниц)
- [ ] Структура: Введение → Разделы → Заключение
- [ ] Аннотация: 5–8 строк
- [ ] Ключевые слова: до 10 слов
- [ ] Формат: A5, Times New Roman, 10pt
- [ ] Поля: верх 2.3, низ 2.5, лево 1.7, право 1.8 см
- [ ] Формулы в MS Equation 3.0
- [ ] Рисунки чёрно-белые/полутоновые
- [ ] Все рисунки пронумерованы и подписаны
- [ ] Все таблицы пронумерованы и названы
- [ ] Список литературы по ГОСТу
- [ ] Десятичные числа через запятую (не точку)
- [ ] Автоматические переносы включены
- [ ] Пробная печать — проверка качества

### Подача

- [ ] Регистрация на [OpenReview](https://openreview.net/group?id=neuroinfo.ru/Neuroinformatics/2026/Conference)
- [ ] Загрузка статьи (PDF + Word)
- [ ] Заполнение метаданных (авторы, аффилиация, секция)
- [ ] Проверка подтверждения подачи
- [ ] Выложено на диск (по требованию А.И. Канева)

### Материалы

- [ ] Статья (DOC + PDF)
- [ ] Презентация (если требуется)
- [ ] Исходный код (опционально)
- [ ] Рисунки в отдельном формате (если нужно)
