#### 3. Математическая модель (2-2.5 страницы)

**3.1. Формулировка задачи классификации точек**

**Вход:**
$$P = \{p_1, ..., p_N\}, \text{ где } p_i = (x, y, z, \text{intensity})$$

**Выход:**
$$C = \{c_1, ..., c_N\}, \text{ где } c_i \in \{1, ..., K\}$$

**Текст для статьи:**
```
Задача семантической сегментации формулируется как задача 
классификации каждой точки облака LiDAR в один из K семантических 
классов (трава, асфальт, лестница, камни, вода)...
```

---

**3.2. Вероятностная модель**

**Формула Байеса:**
$$P(c_i | p_i) = \frac{P(p_i | c_i) \cdot P(c_i)}{P(p_i)}$$

**Байесовское обновление:**
$$P(m | z_{1:t}) \propto \prod_{i=1}^{t} P(z_i | m) \cdot P(m)$$

**Текст для статьи:**
```
Для накопления семантической информации во времени используется 
байесовское обновление карты. Апостериорная вероятность семантического 
класса вычисляется рекурсивно...
```

---

**3.3. Архитектура нейронной сети**

**PointNet encoder:**
$$h_i = \text{MLP}(p_i)$$

**Global pooling:**
$$h_{\text{global}} = \max(\{h_1, ..., h_N\})$$

**Выход:**
$$y = \text{softmax}(\text{MLP}(h_{\text{global}}))$$

**Текст для статьи:**
```
Архитектура сети основана на PointNet [13], что обеспечивает 
инвариантность к перестановке точек. Глобальный pooling через 
операцию max позволяет агрегировать признаки...
```

---

**3.4. Функции потерь**

**Cross-Entropy:**
$$L_{\text{CE}} = -\sum_{i=1}^{K} y_i \log(\hat{y}_i)$$

**Focal Loss:**
$$L_{\text{FL}} = -\alpha_t (1 - \hat{y}_t)^\gamma \log(\hat{y}_t)$$

**Текст для статьи:**
```
Для обучения используется комбинация Cross-Entropy и Focal Loss. 
Focal Loss позволяет бороться с несбалансированностью классов, 
уменьшая вклад хорошо классифицированных примеров...
```

---

#### 4. Метрики оценки качества (1 страница)

**4.1. Метрики для сегментации**

| Метрика | Формула | Диапазон |
|---------|---------|----------|
| Accuracy | $\frac{TP + TN}{TP + TN + FP + FN}$ | [0, 1] |
| Precision | $\frac{TP}{TP + FP}$ | [0, 1] |
| Recall | $\frac{TP}{TP + FN}$ | [0, 1] |
| F1-Score | $2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$ | [0, 1] |
| mIoU | $\frac{1}{K} \sum \frac{TP}{TP + FP + FN}$ | [0, 1] |

**Текст для статьи:**
```
Для оценки качества сегментации используются стандартные метрики... 
Особое внимание уделяется mIoU (mean Intersection over Union), 
который является наиболее информативной метрикой для семантической 
сегментации...
```

---

**4.2. Метрики для навигации**

| Метрика | Формула | Требование |
|---------|---------|------------|
| RMSE | $\sqrt{\frac{1}{N} \sum (z_i^{\text{pred}} - z_i^{\text{true}})^2}$ | < 5 см |
| Успешность | $\frac{N_{\text{successful}}}{N_{\text{total}}} \cdot 100\%$ | > 90% |
| Время планирования | $T_{\text{planning}}$ | < 100 мс |

#### 4. Математическая основа (1 страница)

**4.1. Цифровая модель высот**

**Градиент:**
$$\nabla Z = \left(\frac{\partial Z}{\partial x}, \frac{\partial Z}{\partial y}\right)$$

**Крутизна склона:**
$$\text{slope} = \arctan\left(\sqrt{\left(\frac{\partial Z}{\partial x}\right)^2 + \left(\frac{\partial Z}{\partial y}\right)^2}\right)$$

**Текст для статьи:**
```
Для анализа проходимости вычисляется градиент поверхности и 
крутизна склона. Эти параметры используются для оценки 
проходимости участка местности...
```

---

**4.2. Функция стоимости пути**

**Формула:**
$$\text{Cost}(\text{path}) = \sum (w_d \cdot d_i + w_s \cdot s_i + w_t \cdot t_i)$$

**Веса:**
- $w_d = 0.4$ (дистанция)
- $w_s = 0.3$ (крутизна)
- $w_t = 0.3$ (тип поверхности)

**Текст для статьи:**
```
Функция стоимости пути учитывает три фактора: длину пути, 
крутизну склона и тип поверхности. Веса подбираются 
экспериментально для обеспечения баланса между краткостью 
пути и безопасностью...
```
