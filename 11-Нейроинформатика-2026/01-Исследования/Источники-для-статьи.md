# Источники для статьи (Нейроинформатика-2026)

## Тема
Влияние высоты сенсора и динамики движения на качество семантической классификации terrain для четвероногого робота

---

## Основные источники (для статьи)

### 1. SqueezeSegV3 — наша модель
- **Статья:** SqueezeSegV3: Spatially-Adaptive Convolution for Efficient Point-Cloud Segmentation (ECCV 2020)
- **Ссылка:** https://github.com/chenfengxu714/SqueezeSegV3
- **Для чего:** используем как базовую модель

### 2. L4Dog — ближайший аналог
- **Статья:** L4Dog: Towards BEV Perception for Quadruped Robots in Complex Urban Scenes (ICLR 2026)
- **Ссылка:** https://openreview.net/forum?id=BxGrZFfTp5
- **Для чего:** quadruped + LiDAR perception, первый BEV dataset для собак
- **Примечание:** отозвана (withdrawn), но ссылка рабочая

### 3. GOOSE-Ex
- **Статья:** Excavating in the Wild: The GOOSE-Ex Dataset for Semantic Segmentation (ICRA 2025)
- **Ссылка:** https://arxiv.org/abs/2409.18788
- **Для чего:** semantic segmentation на quadruped (Spot), сравнение платформ

### 4. SemanticKITTI
- **Статья:** SemanticKITTI: A Dataset for Semantic Scene Understanding of LiDAR Sequences (ICCV 2019)
- **Ссылка:** http://semantic-kitti.org/
- **Для чего:** baseline dataset для обучения модели

### 5. QuadBEV
- **Статья:** QuadBEV: An Efficient Quadruple-Task Perception Framework via Bird's-Eye-View Representation (arXiv 2024)
- **Ссылка:** https://arxiv.org/abs/2410.06516
- **Для чего:** современное состояние BEV perception

## Примечание

Датасет планируется создать синтетический на основе Gazebo Harmonic:
- LiDAR данные при разных высотах сенсора (0.5м vs 1.8м)
- Разные режимы движения (REST, STAND, TROT)
- Классы terrain: ground, obstacle, vegetation, steps
