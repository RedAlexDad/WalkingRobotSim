## 8. SWOT-анализ

### Сильные стороны
- C++ код: современный стандарт (17), Eigen3, noexcept, nodiscard
- GPU-ускорение: 1230 строк CuPy, 477 тестов, 10× ускорение
- Docker: 12-этапная сборка, GPU passthrough, Cyclone DDS
- Документация: 81 отчёт, 2739 строк в Obsidian

### Слабые стороны
- **Метрики не считаются** — RMSE/MAE нет
- **Валидация не проведена** — ground truth не существует
- **Costmap shift** — Nav2 не работает корректно
- **Одометрия дрейфует** — не скомпенсировано

### Возможности
- Semantic SLAM — нейросетевая сегментация terrain
- RL для оптимизации походки — MARG, TOP-Nav
- Публикация статьи — Нейроинформатика-2026, ИИАСУ-2027

### Угрозы
- RMSE может не вписаться в норму < 0,05 м
- Costmap без SLAM может не стабилизироваться
- Один разработчик — bottleneck по времени
