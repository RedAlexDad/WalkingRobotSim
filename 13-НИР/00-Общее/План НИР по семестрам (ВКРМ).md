## Логика порядка (1 → 3 → 2 → 4)

Почему главы пишутся не по порядку:

1. **Глава 1** — разобраться в теме, найти аналоги, поставить задачу
2. **Глава 3** — сделать эксперимент, получить первые данные (чтобы понимать, с чем работаешь)
3. **Глава 2** — на основе опыта написать математику метода (без данных — нет смысла)
4. **Глава 4** — итоговые результаты

Аргумент научрука: *«Во второй главе много математики. Писать о ней без первичных результатов — нет смысла.»*
