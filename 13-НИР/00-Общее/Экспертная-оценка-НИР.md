## 9. SWOT-анализ

| Положительное | Отрицательное |
|---|---|
| **Сильные стороны:** | **Слабые стороны:** |
| • C++: современный стандарт (17), Eigen3, noexcept | • **Метрики не считаются** — RMSE/MAE нет |
| • GPU: 1230 строк CuPy, 477 тестов, 10× ускорение | • **Валидация не проведена** — ground truth не существует |
| • Docker: 12-этапная сборка, GPU passthrough, DDS | • **Costmap shift** — Nav2 не работает корректно |
| • Документация: 81 отчёт, 2739 строк в Obsidian | • **Одометрия дрейфует** — не скомпенсировано |

| Возможности | Угрозы |
|---|---|
| • Semantic SLAM — нейросетевая сегментация terrain | • RMSE может не вписаться в норму < 0,05 м |
| • RL для оптимизации походки — MARG, TOP-Nav | • Costmap без SLAM может не стабилизироваться |
| • Статья — Нейроинформатика-2026, ИИАСУ-2027 | • Один разработчик — bottleneck по времени |
