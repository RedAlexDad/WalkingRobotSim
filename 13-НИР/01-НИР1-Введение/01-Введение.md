# Введение

Автономная навигация мобильных роботов остаётся одной из ключевых проблем современной робототехники. Шагающие роботы (особенно четвероногие платформы) демонстрируют уникальные преимущества при перемещении по сложному рельефу: лестницам, каменистой почве, завалам.

Требования к системе автономной навигации:

- Точное восприятие среды через мультимодальные сенсоры (LiDAR, RGB-D, IMU)
- Семантическое понимание среды для классификации типов поверхности
- Адаптивное планирование траекторий с учётом проходимости
- Эффективное управление вычислительными ресурсами для real-time

## Цель работы

Провести комплексный теоретический анализ современного состояния технологий автономной навигации четвероногих роботов с акцентом на интеграцию LiDAR-SLAM, семантического понимания среды и terrain-aware планирования.

## Задачи

1. Рассмотреть применения шагающих роботов в разных сферах
2. Проанализировать инновационные подходы: vision-language модели, terrain-aware, SLAM-free, Deep RL
3. Рассмотреть математическую основу SLAM (фильтр Байеса)
4. Проанализировать методы локализации и картирования
5. Определить технологический стек и архитектуру системы
