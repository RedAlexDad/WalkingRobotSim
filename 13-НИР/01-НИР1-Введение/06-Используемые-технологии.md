# Используемые технологии

## Аппаратная платформа

- Unitree Go1/Go2, Boston Dynamics Spot
- Gazebo Harmonic — физическая симуляция (трение, упругие деформации)

## Программный стек

- **ROS 2 Jazzy** — распределённая архитектура, publish-subscribe, tf2
- **Nav2** — планирование и локализация
- **LiDAR** — облака точек
- **RGB-D камеры** — визуальное восприятие
- **IMU** — оценка ориентации

## Python библиотеки

- **rclpy** — ROS 2 Python API
- **tf2_py** — координатные преобразования
- **NumPy/SciPy** — численные вычисления, матричные операции
- **TensorFlow/PyTorch** — глубокое обучение
- **Deep RL (PPO)** — обучение адаптивных стратегий движения
- **C++/Rust** — высокопроизводительные компоненты real-time
