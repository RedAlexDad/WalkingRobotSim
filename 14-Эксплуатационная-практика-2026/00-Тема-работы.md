# Эссе по эксплуатационной практике

**Тема выпускной работы:** Разработка симуляции шагающего робота для автономной навигации

**Студент:** Папин Алексей Владимирович, ИУ5Ц-21М

**Цель работы:** Разработка симуляционной среды для шагающего робота Unitree Go1/Go2 с интеграцией алгоритмов автономной навигации в сложных условиях. Работа включает математическое исследование семантической сегментации LiDAR данных и terrain-aware планирования, а также практическую разработку модуля Elevation Mapping для построения карты высот в реальном времени.

**Ключевые слова:** автономная навигация, шагающие роботы, семантическая сегментация, terrain-aware планирование, Elevation Mapping, ROS 2, Gazebo Harmonic, глубокое обучение, LiDAR, математическое моделирование
