## 📊 Рекомендации по заполнению

### 1. Сбор данных для сравнения

**Источники:**
- Оригинальные статьи (PointNet, PointNet++, RangeNet++, SuMa++)
- GitHub репозитории с кодом
- Benchmark статьи (SemanticKITTI, KITTI-360)

**Что искать:**
- Точность (mIoU, Accuracy, F1-Score)
- Скорость обработки (Гц, FPS)
- Требования к памяти (MB, GB)
- Требования к вычислениям (FLOPs, параметры)
- Требования к данным (тип LiDAR, количество лучей)

---

### 2. Как заполнять таблицу

**Шаг 1:** Изучить 5-7 аналогов  
**Шаг 2:** Выписать метрики из оригинальных статей  
**Шаг 3:** Указать диапазоны для предлагаемого метода  
**Шаг 4:** Выделить лучшие значения **жирным**  
**Шаг 5:** Добавить ссылки на источники в формате [1], [2], ...

---

### 3. Форматирование для статьи

**Для LaTeX:**
- Использовать `\begin{table}[h]` для плавающих таблиц
- Добавлять `\caption{}` с описанием
- Использовать `\label{}` для ссылок
- Выделять лучшие значения `\textbf{}`

**Для Word:**
- Использовать встроенные стили таблиц
- Добавлять подписи под таблицами
- Нумеровать таблицы (Таблица 1, Таблица 2, ...)
- Выделять лучшие значения **жирным**
