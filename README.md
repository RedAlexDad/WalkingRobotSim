# WalkingRobotSim — Методичка

Методические материалы по проекту симуляции шагающего робота на ROS 2 + Gazebo.

## Структура

| Раздел                     | Описание                                                        |
| -------------------------- | --------------------------------------------------------------- |
| `00-Обзор`                 | Быстрый старт, карта знаний, структура проекта                  |
| `01-Архитектура`           | ROS 2 архитектура, мультироботная система, навигация и SLAM     |
| `02-Контроллеры`           | Crawl, Trot, Stand, Rest, PID, Robot Controller                 |
| `03-Кинематика`            | Прямая и обратная кинематика, трансформации                     |
| `04-Одометрия`             | Одометрия по контакту стоп                                      |
| `04-Сообщения-и-Сервисы`   | RobotBehaviorCommand, RobotFootContact, RobotGaitCommand и др.  |
| `05-Docker-Инфраструктура` | Dockerfile, Docker Compose, CI/CD, Kubernetes                   |
| `06-Методические-указания` | Учебные модули: основы, топики, Docker, архитектура, упражнения |
| `09-Telegram-посты`        | Публикации проекта                                              |
| `10-Нейроинформатика-2026` | План, исследования, эксперименты, черновик статьи               |
| `11-Архив`                 | Шаблоны, чеклисты, литература, трекер прогресса                 |

## Учебные модули (06-Методические-указания)

1. **Основы ROS 2** — команды, глоссарий, квиз
2. **Топики** — публикация/подписка, шпаргалка, квиз
3. **Docker** — контейнеризация проекта, шпаргалка, квиз
4. **Архитектура проекта** — структура пакетов, квиз
5. **Упражнения** — практические задания, чеклист
