## Зачем эта папка

Статья №533, поданная в **PIERE 2026**, **не прошла по формальным
требованиям**, и сроки подачи истекли. ЦПР предложил подать её в **REEPE
2027** (Scopus, IEEE). Параллельно ту же работу можно оперативно издать в
сборнике **РИНЦ конференции ИИАСУ-2026** (русский язык, до 31.10.2026) —
это отдельная, более простая по требованиям публикация.

Здесь собран план адаптации уже готовой статьи (`docs/ieee-article/`) под
требования ИИАСУ-2026 и организационные шаги подачи.

## Быстрый порядок

1. Шаблоны и требования уже скачаны → `template/`; выжимки — в
   `requirements.md` и `template-notes.md`.
2. Взять `docs/ieee-article/draft-article-ru.md` как основу и
   синхронизировать с английской v1.0 (`draft-article-en.md`).
3. По шаблону: УДК, аннотация (650–1000 знаков), ключевые слова (5–7),
   EN-блок; разделы **Введение / Материалы и методы / Результаты /
   Обсуждение / Заключение**; .docx, 4–6 стр., ≥6000 знаков.
4. Оформить ≤4–5 рисунков и ≤2 таблицы, список источников (ГОСТ, ≥5).
5. Заключение об открытом опубликовании через ЦПР (до 31.10.2026).
6. Подать статью в личном кабинете до 31.10.2026.
