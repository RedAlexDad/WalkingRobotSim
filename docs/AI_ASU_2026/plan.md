## 2. Целевые требования (ИИАСУ-2026)

- формат — **.docx** (.pdf не рассматривается);
- A4, поля 2 см, TNR 12, полуторный интервал; **4–6 страниц**,
  **≥6000 знаков**, ≤6 авторов;
- **структура:** УДК, заголовок (6–15 слов), авторы (+SPIN,
  корреспондирующий), аннотация (**650–1000 знаков**), ключевые слова
  (**5–7**), EN-блок, **Введение / Материалы и методы / Результаты /
  Обсуждение / Заключение**, Список источников (**≥5**, по порядку, ГОСТ);
- **таблиц ≤2** (≤20% объёма), **рисунков ≤5**;
- заимствование **≤20%**;
- заключение об открытом опубликовании (ЦПР) до **31.10.2026**.

## 3. Шаги

1. **Подготовка.** ✅ Создана папка `docs/AI_ASU_2026/`. ⏳ Скачать шаблон
   статьи и формальные требования с сайта, заполнить `template-notes.md`
   и `requirements.md`.
2. **Синхронизация RU-версии.** Дописать/перевести недостающие разделы
   (§5.4–5.6 — метрики/таксономия/воспроизводимость, §6.1–6.2 — линейный
   анализ и научные положения P1–P4, §1.1 — постановка/RQ).
3. **Переверстка под шаблон.** УДК, заголовок, авторы (+SPIN,
   корреспондирующий), аннотация (650–1000 знаков), ключевые слова
   (5–7), EN-блок; текст — разделами **«Введение», «Материалы и методы»,
   «Результаты», «Обсуждение», «Заключение»** (в подбор, полужирным, с
   точкой). Формат — .docx.
4. **Объём.** Уложить в 4–6 страниц; при переизбытке — сокращать
   второстепенное (детали дефектов — в краткую таблицу).
5. **Иллюстрации.** **Рисунков ≤5** — берём 4 (`bw/`), подписи под
   рисунками. **Таблиц ≤2** — из трёх заготовок (`tables/*.xlsx`)
   оставить/объединить две (например, «ходьба + рабочая область» и
   «таксономия отказов»); ≤20% объёма.
6. **Литература.** Оформить 15 ссылок по ГОСТ; проверить ID
   `arXiv:2607.18135`.
7. **Вычитка и оригинальность.** Русская вычитка; проверка Антиплагиатом.
8. **Экспортный контроль.** Запрос заключения через ЦПР
   (`conf.cpr@bmstu.ru`).
9. **Подача.** Личный кабинет ИИАСУ-2026 до **31.10.2026**.
