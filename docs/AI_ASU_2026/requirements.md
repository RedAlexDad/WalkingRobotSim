# Формальные требования ИИАСУ-2026 (статья, РИНЦ)

**Источник:** `template/Требования_к_статьям_РИНЦ.docx` (скачан с сайта
`https://rusengineer.bmstu.ru/for-authors/`)
**Статус:** выжимка обязательных требований

---

## 1. Файл и общие условия

- Формат файла — только **MS Word (.doc / .docx)**; **PDF не
  рассматривается**.
- Обязательно **заключение о возможности открытого опубликования**
  (экспортный контроль, через ЦПР).
- Допустимый **объём заимствования — 20%**.
- От одного автора — **не более 3 работ**.

## 2. Объём и оформление

- Объём (включая метаданные) — **4–6 страниц**, минимум **6000 знаков** с
  пробелами.
- **A4**, все поля **2 см**, шрифт **Times New Roman 12**, интервал
  **полуторный**.
- **Запрещены** гиперссылки и разрывы разделов внутри текста.

## 3. Структура (строго)

1. **УДК**
2. **Заголовок статьи**
3. Сведения об авторах
4. Аннотация
5. Ключевые слова
6. Заголовок статьи **на английском**
7. Сведения об авторах на английском
8. Аннотация на английском
9. Ключевые слова на английском
10. **Введение**
11. **Материалы и методы**
12. **Результаты**
13. **Обсуждение полученных результатов**
14. **Заключение**
15. *(Благодарности; финансирование — при наличии; декларация об
    использовании генеративного ИИ — при наличии)*
16. **Список источников**

Названия разделов — в подбор к тексту, полужирным, отделять точкой.

## 4. Метаданные

- **УДК** — подобрать по тематике (teacode.com) или у похожей публикации,
  проверив по классификатору.
- **Заголовок:** **6–15 слов**, без формул, без букв чужих алфавитов и
  аббревиатур (кроме широко принятых); не из нескольких предложений.
- **Авторы:** ФИО полностью, e-mail; аффилиация надстрочным знаком; полное
  название организации, город, страна; **корреспондирующий автор**
  отмечается звёздочкой; при наличии — **SPIN-код**; **≤6 авторов**.
- **Аннотация:** **650–1000 знаков** с пробелами; по шаблону
  «Рассмотрено…, представлено…, показано… Сделаны выводы, что…».
- **Ключевые слова:** **5–7** слов/словосочетаний; аббревиатуры и
  выражения **длиннее 4 слов не допускаются**.
- **Английский блок:** заголовок, транслитерация ФИО (BGN/BSI), перевод
  организаций, аннотация, ключевые слова.

## 5. Тело статьи

- Условные обозначения и сокращения раскрывать при первом упоминании.
- **Формулы:** Equation / MathType или встроенный редактор Word; кегль как
  в тексте; нумеровать только те, на которые есть ссылки; величины
  описывать при первом упоминании.
- **Таблицы:** **до 1–2 шт.**, не более **20%** объёма; нумеровать по
  порядку упоминания; не дублировать графики таблицами.
- **Рисунки:** **до 4–5 шт.**; вставлять сразу после первого упоминания;
  обязательны подрисуночные подписи; элементы сгруппированы; за качество
  отвечает автор.
- **Ссылки в тексте:** в квадратных скобках `[7]` или `[7, с. 17]`; в
  одних скобках **не более 3 источников**.

## 6. Список источников

- **Не менее 5** позиций.
- Формируется **по порядку упоминания** в тексте.
- Источники — **на языке оригинала**; для не-латинских при необходимости
  транслит по BGN.
- Примеры оформления (книга, статья, электронный ресурс, диссертация,
  патент, ГОСТ) — в `template-notes.md`.

## 7. Чек-лист

- [ ] Файл .docx (не PDF)
- [ ] 4–6 страниц, ≥6000 знаков
- [ ] A4, поля 2 см, TNR 12, полуторный интервал
- [ ] УДК + заголовок (6–15 слов) + авторы (≤6, SPIN, контактный)
- [ ] Аннотация 650–1000 знаков + EN-блок
- [ ] Ключевые слова 5–7 (RU и EN)
- [ ] Разделы: Введение, Материалы и методы, Результаты, Обсуждение,
      Заключение
- [ ] Таблиц ≤2, рисунков ≤5, подписи
- [ ] Список источников ≥5, по порядку, ГОСТ-формат
- [ ] Заимствование ≤20%
- [ ] Заключение об открытом опубликовании (ЦПР)
