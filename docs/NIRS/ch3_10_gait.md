# Глава 3. Разработка модуля Elevation Mapping и terrain-aware планирования

## 3.10 Адаптация походки по типу местности

### 3.10.1 Принцип адаптации

Адаптация походки заключается в изменении параметров движения ног в зависимости от traversability под опорами робота. Это позволяет роботу автоматически выбирать оптимальный стиль ходьбы: на ровной поверхности — быстрая походка с минимальной высотой шага, на неровной поверхности — медленная походка с высоким подъёмом ног, на опасной поверхности — остановка и поиск альтернативного маршрута [5].

Для реализации используется нода `gait_adaptor`, которая читает traversability слой карты высот, проецирует позиции опор робота (foot positions) на карту высот, определяет traversability под каждой опорой, вычисляет агрегированную traversability (худшая из опор) и корректирует параметры походки в соответствии с классом terrain.

### 3.10.2 Проецирование опор на карту высот

Позиции опор робота получаются из кинематики (joint states) или из TF-дерева (если foot frames публикуются). Для каждой опоры выполняется трансформация foot_frame  →  map_frame, после чего определяется ячейка карты:

$$
\begin{aligned}
\mathrm{cell}_x &= \left\lfloor \frac{\mathrm{foot}_x - \mathrm{map}\_\mathrm{origin}_x}{\mathrm{resolution}} \right\rfloor \\
\mathrm{cell}_y &= \left\lfloor \frac{\mathrm{foot}_y - \mathrm{map}\_\mathrm{origin}_y}{\mathrm{resolution}} \right\rfloor
\end{aligned}
$$

и $\mathrm{traversability} = \mathbf{t}[\mathrm{cell}_y, \mathrm{cell}_x]$. Если опора находится за пределами карты, используется значение по умолчанию 0,5 (средняя проходимость).

### 3.10.3 Параметры адаптации

Параметры адаптации для различных классов местности приведены в Таблице 3.5.

Таблица 3.5 — Параметры походки для различных классов местности

| Параметр | Safe terrain | Medium terrain | Unsafe terrain |
|----------|-------------|----------------|----------------|
| Высота шага | 0,04 м | 0,08 м | 0,15 м |
| Частота шага | 2,0 Гц | 1,5 Гц | 1,0 Гц |
| Макс. скорость | 0,5 м/с | 0,3 м/с | 0,15 м/с |
| Высота корпуса | 0,25 м | 0,20 м | 0,18 м |

Обоснование параметров: на ровной поверхности достаточно высоты шага 4 см, чтобы не задевать неровности; на сложном рельефе требуется до 15 см для преодоления камней и ступеней. Частота шага снижается на сложном рельефе, чтобы робот имел время для коррекции траектории ноги в воздухе. Опускание корпуса на сложном рельефе снижает центр масс и повышает устойчивость [6].

### 3.10.4 Алгоритм адаптации

Входными данными алгоритма является traversability под опорами [t₁, t₂, t₃, t₄]. Выходные данные — параметры походки (step_height, frequency, speed, body_height).

Вычисление агрегированной traversability:

$$
\mathrm{terrain}\_\mathrm{type} = \min(t_1, t_2, t_3, t_4)
$$

— худшая опора определяет режим.

Если terrain_type > 0,7 (Safe): step_height = 0,04 м, frequency = 2,0 Гц, speed = 0,5 м/с, body_height = 0,25 м, gait_type = "trot" (рысь — эффективная походка).

Если terrain_type > 0,3 (Medium): step_height = 0,08 м, frequency = 1,5 Гц, speed = 0,3 м/с, body_height = 0,20 м, gait_type = "crawl" (ползание — осторожная походка).

Если terrain_type ≤ 0,3 (Unsafe): при distance_to_safe_terrain < emergency_stop_threshold выполняется экстренная остановка (speed = 0, stop = True); в противном случае — step_height = 0,15 м, frequency = 1,0 Гц, speed = 0,15 м/с, body_height = 0,18 м, gait_type = "crawl_slow" (медленная осторожная походка).

### 3.10.5 Плавность перехода

Для обеспечения плавного изменения походки используется экспоненциальное сглаживание:

$$
\mathrm{param}_{\mathrm{current}} = \mathrm{param}_{\mathrm{current}} \times (1 - \alpha) + \mathrm{param}_{\mathrm{target}} \times \alpha, \quad \alpha = 0.3
$$

где $\alpha$ — коэффициент сглаживания. Типичное время перехода между режимами: Safe  —  Medium — около 3–4 шагов (1,5–2 с при частоте 2 Гц), Medium  —  Safe — 2–3 шага, Medium  —  Unsafe — 1–2 шага (быстрая реакция на опасность).

### 3.10.6 Прогнозирование traversability

Для упреждающей адаптации gait_adaptor использует карту traversability в направлении движения. Определяется направление движения (из cmd_vel или goal), на карте traversability выбираются ячейки на пути робота на расстоянии до 2 м вперёд. Если впереди обнаружен сложный участок (traversability < 0,5), параметры походки начинают меняться за 1–2 шага до входа на участок. Это обеспечивает плавное замедление перед сложным участком и своевременное увеличение высоты шага.

### 3.10.7 Типы походок

Для различных режимов traversability используются различные типы походок. Trot (рысь) — диагональные пары ног движутся синхронно, быстрая, эффективная походка для ровных поверхностей. Crawl (ползание) — каждая нога движется независимо, медленная, но устойчивая походка, минимум 3 ноги на земле в любой момент времени, подходит для неровных поверхностей. Crawl_slow — медленная crawl с повышенной высотой шага, максимальное время для каждой фазы переноса ноги, постоянный контроль равновесия.

### 3.10.8 Валидация адаптации

Для проверки корректности адаптации используются следующие тесты: реакция на изменение traversability (робот стоит на ровной поверхности, traversability искусственно изменяется под одной опорой  —  проверка изменения параметров походки), плавность перехода (измерение времени перехода между режимами, проверка отсутствия скачков в параметрах), остановка в no-go зоне (робот движется к непроходимому участку  —  проверка экстренной остановки на безопасном расстоянии) и энергоэффективность (сравнение энергозатрат при движении по неровной поверхности с адаптацией и без) [5].
