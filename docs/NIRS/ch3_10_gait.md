# Глава 3. Разработка модуля Elevation Mapping и terrain-aware планирования

## 3.10 Адаптация походки по типу местности

### 3.10.1 Принцип адаптации

Адаптация походки заключается в изменении параметров движения ног
в зависимости от traversability под опорами робота. Это позволяет
роботу автоматически выбирать оптимальный стиль ходьбы:

- На ровной поверхности: быстрая походка с минимальной высотой шага.
- На неровной поверхности: медленная походка с высоким подъёмом ног.
- На опасной поверхности: остановка и поиск альтернативного маршрута.

Для этого используется нода `gait_adaptor`, которая:

1. Читает traversability слой карты высот.
2. Проецирует позиции опор робота (foot positions) на карту высот.
3. Определяет traversability под каждой опорой.
4. Вычисляет агрегированную traversability (худшая из опор).
5. Корректирует параметры походки в соответствии с классом terrain.

### 3.10.2 Проецирование опор на карту высот

Позиции опор робота получаются из кинематики (joint states)
или из TF дерева (если foot frames публикуются).

Для каждой опоры:
```
foot_frame → transform → map_frame
cell_x = floor((foot_x - map_origin_x) / resolution)
cell_y = floor((foot_y - map_origin_y) / resolution)
t = traversability[cell_y, cell_x]
```

Если опора находится за пределами карты (traversability не определена),
используется значение по умолчанию (0.5 — средняя проходимость).

### 3.10.3 Параметры адаптации

| Параметр | Safe terrain | Medium terrain | Unsafe terrain |
|----------|-------------|----------------|----------------|
| Высота шага | 0.04 м | 0.08 м | 0.15 м |
| Частота шага | 2.0 Гц | 1.5 Гц | 1.0 Гц |
| Макс. скорость | 0.5 м/с | 0.3 м/с | 0.15 м/с |
| Высота корпуса | 0.25 м | 0.20 м | 0.18 м |

**Обоснование параметров:**

- **Высота шага**: на ровной поверхности достаточно 4 см, чтобы не
  задевать неровности. На сложном рельефе требуется до 15 см для
  преодоления камней и ступеней.

- **Частота шага**: на сложном рельефе робот должен делать шаги
  медленнее, чтобы иметь время для коррекции траектории ноги
  в воздухе.

- **Скорость движения**: снижается на сложном рельефе для
  сохранения устойчивости.

- **Высота корпуса**: опускание корпуса на сложном рельефе
  снижает центр масс и повышает устойчивость.

### 3.10.4 Алгоритм адаптации

```
Вход: traversability под опорами [t1, t2, t3, t4]
Выход: параметры походки (step_height, frequency, speed, body_height)

# Вычисление агрегированной traversability
terrain_type = min(t1, t2, t3, t4)  # худшая опора определяет режим

# Адаптация по режимам
if terrain_type > 0.7:
    # SAFE: ровная поверхность
    step_height = 0.04
    frequency = 2.0
    speed = 0.5
    body_height = 0.25
    gait_type = "trot"           # рысь — эффективная походка

elif terrain_type > 0.3:
    # MEDIUM: неровная поверхность
    step_height = 0.08
    frequency = 1.5
    speed = 0.3
    body_height = 0.20
    gait_type = "crawl"          # crawl — осторожная походка

else:
    # UNSAFE: опасная поверхность
    if distance_to_safe_terrain < emergency_stop_threshold:
        step_height = 0.0
        frequency = 0.0
        speed = 0.0
        stop = True              # экстренная остановка
    else:
        step_height = 0.15
        frequency = 1.0
        speed = 0.15
        body_height = 0.18
        gait_type = "crawl_slow"  # медленная осторожная походка
```

### 3.10.5 Плавность перехода

Для обеспечения плавного изменения походки используется
экспоненциальное сглаживание:

```
param_current = param_current * (1.0 - alpha) + param_target * alpha
```

где alpha = 0.3 (коэффициент сглаживания, 0.0 — без изменений,
1.0 — мгновенное изменение).

Типичное время перехода между режимами:
- Safe → Medium: ~3-4 шага (1.5-2 с при 2 Гц).
- Medium → Safe: ~2-3 шага.
- Medium → Unsafe: ~1-2 шага (быстрая реакция на опасность).

### 3.10.6 Прогнозирование traversability

Для упреждающей адаптации gait_adaptor использует карту
traversability в направлении движения:

1. Определяется направление движения (из cmd_vel или goal).
2. На карте traversability выбираются ячейки на пути робота
   на расстоянии до 2 м вперёд.
3. Если впереди обнаружен сложный участок (traversability < 0.5),
   параметры походки начинают меняться за 1-2 шага до входа
   на участок.

Это обеспечивает:
- Плавное замедление перед сложным участком.
- Своевременное увеличение высоты шага.
- Избежание резких переходов, которые могут дестабилизировать
  робота.

### 3.10.7 Типы походок

Для различных режимов traversability используются различные
типы походок:

**Trot (рысь):**
- Диагональные пары ног движутся синхронно.
- Быстрая, эффективная походка для ровных поверхностей.
- Требует хорошего баланса.

**Crawl (ползание):**
- Каждая нога движется независимо.
- Медленная, но устойчивая походка.
- Минимум 3 ноги на земле в любой момент времени.
- Подходит для неровных поверхностей.

**Crawl_slow:**
- Медленная crawl с повышенной высотой шага.
- Максимальное время для каждой фазы переноса ноги.
- Постоянный контроль равновесия.

### 3.10.8 Валидация адаптации

Для проверки корректности адаптации используются следующие тесты:

1. **Реакция на изменение traversability**: робот стоит на
   ровной поверхности, traversability искусственно изменяется
   под одной опорой → проверка изменения параметров походки.

2. **Плавность перехода**: измерение времени перехода между
   режимами, проверка отсутствия скачков в параметрах.

3. **Остановка в no-go зоне**: робот движется к непроходимому
   участку → проверка экстренной остановки на безопасном
   расстоянии.

4. **Энергоэффективность**: сравнение энергозатрат (ток приводов)
   при движении по неровной поверхности с адаптацией и без.
