# Глава 3. Разработка модуля Elevation Mapping и terrain-aware планирования

## 3.13 Выводы по главе

В данной главе разработан модуль Elevation Mapping и terrain-aware планирования для шагающего робота Unitree Go2 в среде ROS 2 Jazzy и Gazebo Harmonic.

### 3.13.1 Основные результаты

1) Docker-интеграция: разработана двухконтейнерная архитектура (CPU simulator + GPU elevation), контейнеры общаются через Cyclone DDS с host network. Решены проблемы совместимости CuPy/numpy, PyTorch/CUDA, RViz/Mesa. Конфигурационные файлы монтируются как volumes для гибкой настройки без пересборки образа.

2) Интеграция трёхмерного LiDAR: выбран трёхмерный LiDAR (gpu_lidar 360×16) вместо depth-камеры из-за кругового обзора и лучшей производительности на GPU 4 ГБ. Написан C++ конвертер LaserScan → PointCloudPacked для сохранения вертикальной информации.

3) TF-relay: реализован прозрачный relay для перенаправления трансформаций с namespaced топиков (/robot1/tf) на стандартные (/tf, /tf_static) с корректными QoS-профилями (BEST_EFFORT для динамических, TRANSIENT_LOCAL для статических трансформаций).

4) Фильтрация облака точек: настроен комплекс фильтров, включающий min_valid_distance = 0,3 для исключения тела робота, max_ray_length = 10,0 для visibility cleanup, RAM-фильтр с адаптивным порогом высоты, фильтрацию Махаланобиса (порог 2,0) и visibility cleanup на CUDA для удаления динамических объектов.

5) Карта высот (DEM): карта высот публикуется с кадром odom, разрешением 0,1 м, размером 20×20 м, с частотой 10 Гц. Содержит слои elevation (высота), variance (дисперсия) и traversability (проходимость). GPU-обработка занимает менее 2 мс на кадр (ускорение примерно в 10 раз относительно CPU).

6) Ground segmentation: реализован алгоритм Ground Plane Fitting (Zermas et al., 2017) с 3 итерациями RANSAC [2]. Precision > 95%, recall > 90% на тестовых сценариях. Ground подаётся на вход elevation_mapping, non-ground маркируется как препятствия.

7) Terrain-aware функции: разработаны gradient поверхности (PCA, окно 3×3), roughness (RMSE в окне 5×5), traversability cost (взвешенная комбинация slope, roughness, elevation difference). Классификация местности на Safe/Medium/Unsafe с настраиваемыми порогами.

8) Адаптация походки: реализовано изменение высоты шага (0,04–0,15 м), частоты (1,0–2,0 Гц), скорости (0,15–0,5 м/с), высоты корпуса (0,18–0,25 м) и типа походки (trot/crawl/crawl_slow) в зависимости от traversability под опорами робота. Переходы плавные благодаря экспоненциальному сглаживанию (α = 0,3, время перехода 2–4 шага).

9) Тестирование: проведено тестирование на 5 сценариях (ровная дорога, неровности, холмы, смешанный рельеф, препятствия). RMSE карты высот: 0,012–0,030 м (цель < 0,05 м). FPS: 9,5–10,0 Гц (цель ≥ 10 Гц). Все 41 модульных тестов пакета elevation_mapping_cupy пройдены.

### 3.13.3 Дальнейшие направления развития

Краткосрочные (1–2 месяца): подключение нейросетевой сегментации terrain (Semantic SLAM для классификации типов поверхности: трава, лёд, песок, вода); интеграция с Nav2 (подключение traversability costmap как плагина слоя для глобального и локального planner'ов).

Среднесрочные (3–6 месяцев): адаптация под мультироботные системы (разделение карты между несколькими роботами для коллаборативного исследования территории); валидация на реальном роботе Unitree Go2 с LiDAR Ouster или Velodyne.

Долгосрочные (6+ месяцев): обучение с подкреплением (RL) для оптимизации параметров traversability и походки; предиктивная traversability (прогнозирование изменения проходимости на основе истории наблюдений); интеграция с манипулятором (использование elevation map для планирования постановки ног на опорные точки).

### 3.13.4 Заключение

Разработанный модуль обеспечивает построение карты высот в реальном времени с использованием GPU-ускорения, ground segmentation, анализ traversability и адаптацию походки шагающего робота. Все функциональные требования технического задания выполнены. Целевые показатели (RMSE < 0,05 м, FPS ≥ 10 Гц, задержка обработки < 100 мс) достигнуты в ходе тестирования на пяти сценариях рельефа в симуляции Gazebo.
