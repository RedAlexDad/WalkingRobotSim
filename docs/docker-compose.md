# 🐳 Управление Docker Compose

## 📋 Описание

Этот документ описывает использование улучшенного скрипта `docker-compose.sh` для управления контейнеризованным окружением проекта WalkingRobotSim. Скрипт предоставляет удобный интерфейс для работы с Docker Compose и включает расширенные функции по сравнению с базовым `run-compose.bash`.

## 🚀 Быстрый старт

1. Сделайте скрипт исполняемым:

   ```bash
   chmod +x docker-compose.sh
   ```

2. Соберите Docker-образ:

   ```bash
   ./build.bash --robot-type Go2
   ```

3. Запустите контейнер:
   ```bash
   ./docker-compose.sh up
   ```

## 📋 Доступные команды

| Команда   | Описание                               |
| --------- | -------------------------------------- |
| `up`      | Запустить контейнер в фоновом режиме   |
| `down`    | Остановить и удалить контейнер         |
| `start`   | Запустить существующий контейнер       |
| `stop`    | Остановить контейнер                   |
| `restart` | Перезапустить контейнер                |
| `status`  | Показать статус контейнера             |
| `logs`    | Показать логи контейнера               |
| `exec`    | Подключиться к контейнеру через bash   |
| `build`   | Пересобрать Docker-образ               |
| `clean`   | Очистить неиспользуемые ресурсы Docker |

## ⚙️ Опции

| Опция        | Описание                                 |
| ------------ | ---------------------------------------- |
| `--sudo`     | Использовать sudo для команд docker      |
| `--no-cache` | Пересобрать образ без использования кэша |
| `--help`     | Показать справку                         |

## 📖 Примеры использования

### Запуск контейнера

```bash
./docker-compose.sh up
```

### Остановка контейнера

```bash
./docker-compose.sh down
```

### Пересборка образа без кэша

```bash
./docker-compose.sh build --no-cache
```

### Подключение к запущенному контейнеру

```bash
./docker-compose.sh exec
```

### Очистка неиспользуемых ресурсов Docker

```bash
./docker-compose.sh clean
```

### Использование с sudo

```bash
./docker-compose.sh --sudo up
```

## 🛠️ Требования

- Docker
- Docker Compose
- Права доступа к Docker (или использование с `--sudo`)

## 📄 Лицензия

Этот скрипт распространяется под той же лицензией, что и основной проект - Apache 2.0.
