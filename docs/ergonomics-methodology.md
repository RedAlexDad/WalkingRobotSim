## 1. Что проект даёт для эргономики

Диплом — это система управления шагающим роботом, где есть всё для
эргономической работы по АСОИУ:

| Компонент проекта | Эргономический аспект |
|---|---|
| RViz, визуализация робота и маршрута | информационная модель (ИМ) состояния робота |
| Телеметрия (высота Z, углы суставов, скорость, дрейф, шаги) | восприятие сложной динамической информации |
| Odometry, odometry_node | источник данных для ИМ |
| rviz_waypoint_tool | интерфейс задания целевых точек оператором |
| YOLO-перцепция (yolo_detector) | канал информации для оператора |
| RL-политика vs детерминированный контроллер | распределение функций человек—машина, подсистемы ИИ в контуре управления |
| ROS2-топики / мосты | потоки данных АСОИУ |

Ключевой факт: **робот управляется в контуре с оператором** (RViz +
waypoint-инструмент + телеметрия), поэтому темы про человеко-машинный
интерфейс, информационные модели и средства отображения ложатся на
проект напрямую — результаты КР можно использовать в дипломе и
наоборот.

## 3. Рекомендация

### Основная рекомендация: **A2** (или A1 при желании углубить в СДП)

> **Разработка и оценка информационной модели состояния шагающего
> робота для человека-оператора в контуре управления**

Почему:

1. **Прямое пересечение с дипломом.** Панель оператора (RViz) и каналы
   телеметрии уже есть в проекте — КР становится исследовательской
   частью диплома, а не «работой ради оценки».
2. **Соответствует варианту В1 методички.** Это аналитический путь:
   проблема → задача → модель → приоритеты характеристик ЭО → оценка →
   экспертиза → обоснование. Полностью ложится на схему этапов.
3. **Выполнимо в срок.** Не требует новых экспериментов с роботом — только
   существующая телеметрия и экспертные оценки.
4. **Даёт материал для публикации.** Из КР вырастает статья (вариант В2
   требует печатной статьи, но и для В1 желательна аналитическая) —
   совпадает с целями PIERE.

### Если нужен обзорный путь (В2) — рекомендация: B2

> **Системный анализ интерфейсов человек-оператор в системах управления
> квадропедами**

Почему: обзор интерфейсов (включая наш ROS2+RViz) ложится на главу
«Современное состояние» диплома; завершается статьёй, что совпадает с
требованием В2 «подготовка статьи для печати».

## 4. Что уточнить перед выбором

1. Какой **вариант КР** закреплён (В1 аналитический или В2 обзорный) —
   это задаёт структуру РПЗ и наличие обязательной статьи.
2. Есть ли в проекте **реальный интерфейс оператора** для оценки
   (RViz-панель, rviz_waypoint_tool) или только симуляция без UI.
3. Требуется ли **участие группы экспертов** (для В1 — экспертная
   оценка; достаточно 5–7 одногруппников).
4. Согласовать формулировку с преподавателем — обычно название темы
   корректируют под диплом.
