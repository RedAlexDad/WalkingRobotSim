# Обоснование выбора модели машинного обучения (методика)

**Дата:** 2026-10-13
**Назначение:** единая методика объективного выбора модели МО для
распознавания объектов (мобильный робот).
**Формат:** связный отчёт: постановка → характеристики → метод → расчёт →
результат.

---

## 1. Резюме

Даны несколько готовых моделей МО. Нужно выбрать **одну лучшую** и
**доказать** выбор. Методика:

1. **разложить модель на части** и задать **характеристики с формулами**;
2. **отсеять** модели по жёстким требованиям;
3. **ранжировать** оставшиеся (показатель $\Phi$ / метод рангов);
4. применить **критерии принятия решений в условиях неопределённости**;
5. **посчитать баллы** и выбрать модель.

Принципы: **объективно**, **без весов** и **без Парето**, **без датасетов
и экспериментов** — только по архитектуре модели. Итог методики на нашем
наборе — **YOLO11n**.

---

## 2. Постановка задачи

**Дано:** множество моделей $A=\{A_1,\dots,A_n\}$ (готовые, не обучаем).
**Найти:** $A^\ast$ — лучшую для задачи.
**Ограничения:** оценка объективная, извлекается из самой модели
(параметры, FLOPs, слои, тип выхода), без прогонов на данных.
**Неопределённость:** заранее неизвестна сложность сцены — учитываем её
через «состояния» (см. §8).

## 6. Методика расчёта (формулы)

**Свёрточный слой** ($k_h\times k_w$, $C_{in}$, $C_{out}$, выход $H\times W$):
$$P_{conv}=k_hk_wC_{in}C_{out}+C_{out},\quad
F_{conv}=2k_hk_wC_{in}C_{out}HW$$

**Линейный слой:** $P_{fc}=IO+O$, $F_{fc}=2IO$.

**Трансформерный блок** ($d$, длина $n$):
$$P_{blk}=12d^2+4d,\qquad F_{blk}\approx24nd^2+4n^2d$$

**Рецептивное поле:** $R_{rf}=1+\sum_i(k_i-1)\prod_{j<i}s_j$.

**Производные:**
$$M=4P,\quad T=\frac{F}{\Pi},\quad f=\frac1T,\quad E=\frac1F,\quad Q=P_{pow}T$$

**Ёмкость:** $R\le\prod_i\sum_{j=1}^d\binom{n_i}{j}$, $\mathrm{VCdim}=O(WL\log W)$.

## 7. Алгоритм выбора

### 7.1. Фильтры (отсев)

Допустимыми остаются модели, прошедшие жёсткие требования:
$$A=\{\,m:\ \forall c\in C_f\ \ \delta_c x_c(m)\ge\lambda_c\,\}$$
(например, $T\le T_{\max}$, $M\le M_{\max}$, нужный тип выхода).

### 7.2. Показатель пригодности

Нормализация по данным (без весов):
$$z_c(m)=\frac{\delta_c x_c(m)-\min_{m'}\delta_c x_c(m')}
{\max_{m'}\delta_c x_c(m')-\min_{m'}\delta_c x_c(m')}\in[0,1]$$
$$\Phi(m)=\frac1{|C_r|}\sum_{c\in C_r} z_c(m),\qquad
m^\ast=\arg\max_{m\in A}\Phi(m)$$

### 7.3. Эквивалент — метод рангов

$$S(m)=\sum_{c\in C_r} r_c(m),\quad m^\ast=\arg\min_{m\in A} S(m)$$
Ничья — лексикографически по приоритетному списку (без весов).

## 8. Критерии принятия решений в условиях неопределённости

**Состояния $\theta_j$:** сложность сцены — 5 / 20 / 50 объектов.
**Выигрыш $a_{ij}$:** достижимая частота
$f_{ij}=\Pi/(F_i+\alpha N_j^2)$ (растёт стоимость постобработки).
Альтернативы — модели $A_i$.

| Критерий | Формула | Смысл |
| --- | --- | --- |
| Лаплас | $\bar a_i=\frac1m\sum_j a_{ij}$, $\max$ | равные вероятности сцен |
| Оптимизм | $M_i=\max_j a_{ij}$, $\max$ | расчёт на лучший случай |
| Вальд | $W_i=\min_j a_{ij}$, $\max$ | расчёт на худший случай |
| Сэвидж | $r_{ij}=\max_i a_{ij}-a_{ij}$, $R_i=\max_j r_{ij}$, $\min$ | минимум сожаления |
| Гурвиц | $H_i=\alpha\max_j a_{ij}+(1-\alpha)\min_j a_{ij}$, $\max$ | компромисс |

$$\pi_i^{(k)}=n-r_i^{(k)}+1,\quad P_i=\sum_k\pi_i^{(k)},\quad
A^\ast=\arg\max_i P_i$$

## 10. Обоснование и практическое применение

**Доказательства (числа):**
1. самая быстрая — 15.09 Гц (у YOLOv8n 11.20, YOLO11s 4.60);
2. держит $\ge10$ Гц в сложной сцене — 10.99 (у YOLOv8n 8.77);
3. самая лёгкая — 2.62 млн, память 10.5 МБ, энергия 0.66 Дж;
4. нулевое сожаление $R=0$ — нигде не проигрывает;
5. первое место по всем пяти критериям, сумма **35** баллов.

**Практика:** на борту даёт $\ge10$ Гц даже в сложной сцене; экономит
память и энергию; к ней легко добавить трекинг. При необходимости маски —
YOLO11n-seg; при экстремальной сложности и приоритете точности — тяжёлые
модели (RT-DETR/Mask R-CNN).
