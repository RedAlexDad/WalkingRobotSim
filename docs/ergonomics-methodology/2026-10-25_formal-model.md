# Формальная модель эргономического ядра

**Дата:** 2026-10-25  
**Тема:** «Эргономическое обеспечение деятельности оператора при обнаружении аномалий шагающего робота» — **резервная линия**.  
**Статус:** текущая тема КР — время реакции (`reaction-time/2026-10-25_concept.md`); этот документ сохранён как формальная модель резервной линии.

---

## 1. Назначение модели

Модель описывает цепочку:

`аномалия → детектор → информационная модель → оператор → действие`

и позволяет рассчитать четыре эргономические характеристики:

- `P_обн` — вероятность обнаружения аномалии;
- `P_лт` — вероятность ложной тревоги;
- `T_обн` — время обнаружения и реакции;
- `K_загр` — загрузку оператора.

Технические параметры детектора (`P_D`, `P_FA`, задержка) входят в модель как входные данные, но не являются эргономическими характеристиками.

## 3. Базовая модель обнаружения

### 3.1. Чувствительность детектора

По модели равновариативного гауссова сигнального обнаружения:

`d'_tech = z(P_D) - z(P_FA)`,

где `z(p) = Φ⁻¹(p)`, `Φ` — функция стандартного нормального распределения.

### 3.2. Влияние информационной модели

Информационная модель не создаёт новую информацию, а определяет, насколько полно оператор может использовать признаки детектора и телеметрии:

`d' = η_IM * d'_tech`, `0 < η_IM ≤ 1`.

`η_IM = 1` означает, что ИМ не ухудшает доступность признаков; `η_IM < 1` — потери из-за плотности, контраста, кодирования, задержки или неоднозначности отображения. Значение `η_IM` должно измеряться или обосновываться отдельно; в модели это не свободный «вес», а параметр эффективности ИМ.

### 3.3. Вероятности обнаружения и ложной тревоги

`P_обн = Φ(d'/2 - c)`,

`P_лт = Φ(-d'/2 - c)`.

При ограничении `P_лт ≤ α` оптимальный по Нейману–Пирсону критерий:

`c* = -d'/2 - z(α)`,

`P_обн,max = Φ(d' + z(α))`.

Таким образом, при фиксированном `α` максимизация `P_обн` эквивалентна максимизации `d'`, то есть выбору ИМ с максимальной `η_IM` при данном детекторе.

### 3.4. Двухступенчатое уточнение

Если детектор выдаёт тревогу, а оператор её проверяет, итоговая вероятность:

`P_обн = P_D * P_обн|A + (1 - P_D) * P_обн|¬A`,

`P_лт = P_FA * P_лт|A + (1 - P_FA) * P_лт|¬A`.

Здесь `P_обн|A` и `P_обн|¬A` — вероятность правильного решения оператора при наличии и отсутствии тревоги. Эта форма используется, если есть данные о поведении оператора в обоих режимах; базовая модель §3.3 остаётся аналитическим приближением.

---

## 4. Модель времени

`T_обн = T_лат + T_поиск + T_реш + T_действ`.

- `T_лат = 0,16–0,24 с` — латентный период зрительной реакции (лекция 7).
- `T_поиск = t_ип = ((E + a) / a * (1 + H_α)) * t_фик` — время информационного поиска (лекция 15).
- `T_реш = a_H + b_H log2(N_alt)` — время выбора из `N_alt` альтернатив (закон Хика); коэффициенты `a_H`, `b_H` калибруются по литературе или пилоту.
- `T_действ` — моторное время реакции; принимается по нормативу или пилоту.

Критерий: `T_обн ≤ T_доп`, где `T_доп` — допустимое время реакции из требований безопасности и темпа управления.

---

## 5. Модель загрузки

`K_загр = (N_аном * T_обн + N_ложн * T_пров) / T_см`.

- `N_аном = λ_аном * T_см` — число аномалий за смену;
- `N_ложн = λ_ложн * T_см` — число ложных тревог за смену;
- `T_пров` — время проверки одной ложной тревоги;
- `T_см` — длительность смены.

Критерий: `K_загр ≤ K_доп`. Величина `K_доп` задаётся из норм труда и отдыха или требований к темпу; она не подбирается по результатам сравнения.

---

## 6. Правило выбора

Для каждого варианта ИМ и порога тревоги:

1. Проверить `P_лт ≤ α`, `T_обн ≤ T_доп`, `K_загр ≤ K_доп`.
2. Среди допустимых вариантов максимизировать `P_обн`.
3. При равенстве `P_обн` — минимизировать `T_обн`.
4. При равенстве `T_обн` — минимизировать `P_лт`.

Веса, экспертные баллы, попарные предпочтения и Парето не используются.

---

## 7. Что является техническим, а что эргономическим

| Слой | Величины | Роль |
|---|---|---|
| Технический | `P_D`, `P_FA`, задержка детектора, разрешение, контраст, частота кадров | Входные данные и ограничения |
| Эргономический | `P_обн`, `P_лт`, `T_обн`, `K_загр`, `η_IM`, `c` | Характеристики деятельности оператора |
| Решение | правило §6 | Детерминированный выбор без весов |

`P_D` и `P_FA` сами по себе не являются эргономическими характеристиками. Они становятся входом в модель, где итоговые вероятности описывают деятельность оператора.

## 8. Данные и допущения

### 8.1. Что нужно извлечь

- `P_D`, `P_FA` детектора по классам аномалий — из ROC/матрицы ошибок, а не из mAP напрямую;
- `η_IM` — из пилота или из модели влияния параметров ИМ; до пилота — сценарий/литература с явной пометкой;
- `T_лат`, `t_фик`, `E`, `a`, `H_α` — из лекций 7 и 15 и параметров ИМ;
- `T_реш`, `T_действ` — из литературы/пилота;
- `λ_аном`, `λ_ложн`, `T_пров`, `T_см` — из сценария;
- `α`, `T_доп`, `K_доп` — из требований безопасности и темпа.

### 8.2. Допущения

- равновариативная гауссова модель сигнального обнаружения;
- независимость событий и проверок;
- `η_IM` постоянна в пределах выбранного варианта ИМ;
- оператор использует критерий, близкий к оптимальному по Нейману–Пирсону; фактический `c` проверяется в пилоте;
- двухступенчатая модель применяется только при наличии данных по обоим режимам.

### 8.3. Ограничения

- без пилота `P_обн`, `P_лт`, `T_обн`, `K_загр` остаются аналитическими;
- `P_D`/`P_FA` по классам аномалий ещё не извлечены;
- сценарии 5/20/50 объектов не прогонялись;
- p95, F1 и ECE измерены только на `showroom`;
- результаты нельзя переносить на все домены.

## 9. План проверки и чувствительности

1. Извлечь `P_D`/`P_FA` из телеметрии/матриц ошибок по классам `A1–A3`.
2. Реализовать формулы §3–§6 в Python.
3. Прогнать сетку `η_IM = 0,5–1,0`, `α = 0,01–0,1`, `T_пров = 1–10 с`.
4. Проверить устойчивость ранжирования вариантов ИМ.
5. Сравнить аналитические `P_обн`, `P_лт`, `T_обн`, `K_загр` с пилотом, если он появится.
6. Все непроверенные величины помечать как «не проверено».
