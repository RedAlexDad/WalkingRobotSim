**Тема:** «Эргономическая оценка информационной модели критичных
параметров шагающего робота для оператора: сравнение форм представления
телеметрии».

**Объект** — экран оператора (информационная модель), а не состояние
робота.

**Анализ** — сравнение форм представления критичных параметров
(числовая / графическая / пространственная / комбинированная).

**Эффективность** — измеримо: время и точность считывания, нагрузка на
внимание, своевременность обнаружения аномалии. Оценка — методом
экспертных оценок с опорой на нормы эргономики (без испытаний с
реальными операторами).

**Вопрос:** верна ли такая постановка, и правильно ли выбран объект
анализа (экран оператора)?
