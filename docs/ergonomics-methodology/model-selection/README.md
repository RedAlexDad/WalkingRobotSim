## Порядок работы

1. **Собрать полную информацию** по каждой модели (файлы `models/*`).
2. **Проанализировать** — свести все характеристики в матрицу
   (`selection-math.md`, §3).
3. **Применить алгоритм** (отсев → нормализация → $\Phi$ / ранги).
4. **Выбрать лучшую** и обосновать.

## Текущий результат

По формальному алгоритму (отсев по $T\le0.1$ с, $M\le64$ МБ, тип —
рамка) допустимы YOLO11n, YOLOv8n, CNN+LSTM; показатель пригодности
$\Phi$: YOLO11n = 0.875 (максимум). **Выбор: YOLO11n.**
