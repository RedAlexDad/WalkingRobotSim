# Модель 01: YOLO11n

**Семейство:** одностадийный CNN-детектор
**Источник:** Ultralytics, `docs.ultralytics.com/models/yolo11/`
**Задача:** детекция объектов
**Вход:** 640×640, 3 канала

---

## 1. Спецификации (официальные)

| Параметр | Значение |
| --- | --- |
| Масштаб (depth, width, max_ch) | 0.50, 0.25, 1024 |
| Слоёв | 181 |
| Параметры $P$ | 2.62 млн |
| FLOPs | 6.6 Г |
| mAP (COCO, справ.) | 39.5 |
| Классов $k$ | 80 |
| Выход | рамка + класс + уверенность |
| NMS | да |
| Стадии | 1 (P3/8, P4/16, P5/32) |

## 2. Архитектура

- **Backbone:** conv + C3k2 + SPPF + C2PSA.
- **Neck:** FPN/PAN (upsample + concat C3k2).
- **Head:** Detect (anchor-free) по P3, P4, P5.
