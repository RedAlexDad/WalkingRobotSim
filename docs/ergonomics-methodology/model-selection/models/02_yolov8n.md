# Модель 02: YOLOv8n

**Семейство:** одностадийный CNN-детектор
**Источник:** Ultralytics, `docs.ultralytics.com/models/yolov8/`
**Задача:** детекция объектов
**Вход:** 640×640, 3 канала

---

## 1. Спецификации

| Параметр | Значение |
| --- | --- |
| Масштаб (depth, width, max_ch) | 0.33, 0.25, 1024 |
| Слоёв | 129 |
| Параметры $P$ | 3.16 млн |
| FLOPs | 8.9 Г |
| mAP (COCO, справ.) | 37.3 |
| Классов $k$ | 80 |
| Выход | рамка + класс |
| NMS | да |
| Стадии | 1 (P3/8, P4/16, P5/32) |

## 2. Архитектура

- **Backbone:** conv + C2f + SPPF.
- **Neck:** FPN/PAN (upsample + concat C2f).
- **Head:** Detect (anchor-free split).
