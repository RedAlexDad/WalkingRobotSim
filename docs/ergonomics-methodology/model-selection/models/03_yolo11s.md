# Модель 03: YOLO11s

**Семейство:** одностадийный CNN-детектор
**Источник:** Ultralytics, `docs.ultralytics.com/models/yolo11/`
**Задача:** детекция объектов
**Вход:** 640×640, 3 канала

## 2. Архитектура

- **Backbone:** conv + C3k2 + SPPF + C2PSA.
- **Neck:** FPN/PAN.
- **Head:** Detect (anchor-free).
