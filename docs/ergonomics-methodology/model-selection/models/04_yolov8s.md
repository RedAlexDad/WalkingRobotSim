# Модель 04: YOLOv8s

**Семейство:** одностадийный CNN-детектор
**Источник:** Ultralytics, `docs.ultralytics.com/models/yolov8/`
**Задача:** детекция объектов
**Вход:** 640×640, 3 канала

---

## 2. Архитектура

- **Backbone:** conv + C2f + SPPF.
- **Neck:** FPN/PAN.
- **Head:** Detect (anchor-free split).
