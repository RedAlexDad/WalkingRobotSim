# Модель 05: RT-DETR-l

**Семейство:** трансформерный детектор (set-prediction)
**Источник:** Ultralytics / Baidu, `docs.ultralytics.com/models/rtdetr/`
**Задача:** детекция объектов
**Вход:** 640×640, 3 канала

---

## 1. Спецификации

| Параметр | Значение |
| --- | --- |
| Параметры $P$ | ≈32 млн |
| FLOPs | ≈103.5 Г |
| AP (COCO, справ.) | 53.0 |
| Классов $k$ | 80 |
| Выход | рамка + класс |
| NMS | **нет** (set-prediction) |
| Число запросов $N_q$ | 300 |
| Слоёв декодера | 6 |
| Стадии | encoder + decoder (гибридный) |

## 2. Архитектура

- **Backbone:** CNN (ResNet-подобный).
- **Encoder:** гибридный (AIFI intra-scale + CCFM cross-scale).
- **Decoder:** 6 слоёв, 300 запросов, Hungarian-сопоставление при обучении.

## 4. Примечания

- Отсеивается по времени и памяти. Инференс детерминирован; обучение с
