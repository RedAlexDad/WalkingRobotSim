# Модель 06: Faster R-CNN (R50-FPN)

**Семейство:** двухстадийный CNN-детектор
**Источник:** Ren et al. (2015), torchvision/Detectron2 (`pytorch.org/vision`)
**Задача:** детекция объектов
**Вход:** 800×1333 (стандарт; в 640×640 FLOPs ≈ 0.38×)

---

## 1. Спецификации

| Параметр | Значение |
| --- | --- |
| Backbone | ResNet-50 + FPN |
| Параметры $P$ | ≈41.5 млн |
| FLOPs | ≈180 Г (при 800×1333) |
| Классов $k$ | 80 |
| Выход | рамка + класс |
| NMS | да |
| Стадии $N_s$ | **2** (RPN → RoI-головы) |
| Предложений $N_{prop}$ | ≈300 |

## 2. Архитектура

- **Backbone:** ResNet-50.
- **Neck:** FPN (P2–P6, 5 уровней).
- **RPN:** анкеры → предложения.
- **Head:** RoI pooling + FC (класс + регрессия).
