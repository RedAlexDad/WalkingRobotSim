# Модель 07: Mask R-CNN (R50-FPN)

**Семейство:** двухстадийный CNN (детекция + сегментация)
**Источник:** He et al. (2017), torchvision/Detectron2
**Задача:** детекция + маска объекта
**Вход:** 800×1333 (стандарт)

---

## 1. Спецификации

| Параметр | Значение |
| --- | --- |
| Backbone | ResNet-50 + FPN |
| Параметры $P$ | ≈44.2 млн |
| FLOPs | ≈250 Г (при 800×1333) |
| Классов $k$ | 80 |
| Выход | **маска** + рамка + класс |
| NMS | да |
| Стадии $N_s$ | **2** |
| Предложений $N_{prop}$ | ≈1000 |

## 2. Архитектура

- **Backbone:** ResNet-50.
- **Neck:** FPN.
- **RPN:** анкеры.
- **Head:** RoIAlign + FC (класс, рамка) + mask-голова (свёрточная).
