# Модель 08: YOLO11n-seg

**Семейство:** одностадийный CNN (детекция + сегментация)
**Источник:** Ultralytics, `docs.ultralytics.com/models/yolo11/`
**Задача:** детекция + маска объекта
**Вход:** 640×640, 3 канала

---

## 1. Спецификации

| Параметр | Значение |
| --- | --- |
| Масштаб (depth, width, max_ch) | 0.50, 0.25, 1024 |
| Параметры $P$ | 2.9 млн |
| FLOPs | 9.8 Г |
| mAP box / mask (COCO, справ.) | 38.9 / 32.0 |
| Классов $k$ | 80 |
| Выход | **маска** + рамка + класс |
| NMS | да |
| Стадии | 1 (P3/8, P4/16, P5/32) |

## 2. Архитектура

- **Backbone:** conv + C3k2 + SPPF + C2PSA.
- **Neck:** FPN/PAN.
- **Head:** Segment (детекция + mask-ветвь).

## 4. Примечания

- Лёгкая **маска**; проходит по времени и памяти (на грани $f\ge10$).
- Выбирается, если по задаче нужна маска, а тяжёлый Mask R-CNN не подходит.
