# Модель 09: CNN + LSTM (рекуррентная)

**Семейство:** одностадийный CNN + **рекуррентный** модуль (трекинг во времени)
**Основа:** YOLO11n + LSTM
**Задача:** детекция + временной трекинг
**Вход:** 640×640, 3 канала + последовательность кадров

---

## 1. Спецификации

| Параметр | Значение |
| --- | --- |
| Детектор | YOLO11n ($P=2.62$ млн, $F=6.6$ Г) |
| Рекуррентный модуль | LSTM, $d=h=256$, $T=10$ шагов |
| $P_{lstm}$ | $4(dh+h^2+h)\approx0.525$ млн |
| $F_{lstm}$ | $8(dh+h^2)\approx1.05$ МFLOP/шаг |
| Итого $P$ | ≈3.15 млн |
| Итого $F$ | ≈6.61 Г |
| Выход | рамка + класс + трек |

## 2. Архитектура

- **Детектор:** YOLO11n (см. модель 01).
- **Рекуррентный блок:** LSTM по признакам/трекам.
- **Особенность:** обработка **последовательная** во времени — не
  распараллеливается.
