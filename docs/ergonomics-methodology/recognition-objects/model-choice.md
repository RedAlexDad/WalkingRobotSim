## 1. Задача

Даны **несколько готовых моделей** машинного обучения (распознавание
объектов). Нужно **выбрать одну** и **обосновать** выбор **по
характеристикам** — объективно, без экспериментов, без датасетов, без
весов («смотрим на число, сравниваем»).

Каждая характеристика оформляется как: **что это · формула · единицы** ·
**как считается аналитически** (по модели).

## 3. Характеристики (определение · формула · единицы)

> **Важно.** У Горячкина Б.С. приоритет — **аналитический расчёт без
> датасетов**. Поэтому для каждой характеристики даны два способа:
> **(А) аналитический** (по архитектуре/параметрам модели — основной) и
> **(Б) по данным** (через датасет — запасной, к согласованию).

### 3.1. Однозначность класса ($O$)

**Что это.** Свойство модели относить объект **к одному классу**, а не
«размазывать» решение по нескольким.

- **(А) Аналитически (по решающему правилу):** если выход модели —
  многоклассовый с одним максимумом, однозначность максимальна;
  если мультиметка/несколько выходов на объект — ниже.

$$O = \frac{1}{k}, \qquad k = \text{число классов на один объект выхода}$$

  Единицы: безразмерная (0…1). Для однозначной классификации $O=1$.
- **(Б) По данным (отрыв топ‑1/топ‑2):**

$$O = \frac{p_{(1)} - p_{(2)}}{p_{(1)}}$$

  Единицы: безразмерная (0…1).

### 3.2. Различимость ($R$)

**Что это.** Способность модели **разделять** классы (объекты не
«сливаются»).

- **(А) Аналитически (ёмкость разделения):** число линейных/решающих
  областей сети как мера различительной способности (для ReLU-сетей
  оценивается по глубине/ширине) или VC-размерность.
- **(Б) По данным (отношение Фишера):**

$$R = \frac{\lVert \mu_1 - \mu_2 \rVert^2}{\sigma_1^2 + \sigma_2^2}$$

  где $\mu$, $\sigma^2$ — средние и дисперсии признаков классов.
  Единицы: безразмерная (чем больше, тем лучше разделимы).

### 3.3. Эффективность ($E$)

**Что это.** Вычислительная эффективность модели как «вычислителя».

$$E = \frac{1}{\text{FLOPs}} \quad\text{или}\quad E = \frac{Q}{T},\
E = \frac{Q}{W}$$

где FLOPs — число операций, $T$ — время расчёта, $W$ — память, $Q$ —
объём полезного результата. Все величины **считаются по архитектуре**
(число слоёв, каналов, разрешение), без прогонов.
Единицы: 1/FLOP, ед./с, ед./байт.

### 3.4. Читаемость ($C$)

**Что это.** Интерпретируемость модели (насколько она «читаема»).

$$C = f(N, L, \text{типы слоёв})$$

где $N$ — число параметров, $L$ — глубина; «прозрачные» модели (деревья,
линейные) читаемее «чёрных ящиков».
Единицы: счётные (число параметров — шт.), порядковая оценка типов.

### 3.5. Наглядность ($H$)

**Что это.** Насколько результат **понятен и заметен** оператору
(свойство выходного представления).

$$H = \frac{1}{\log_2(k+1)}$$

где $k$ — число одновременно выводимых сущностей (по Хику–Хайману);
либо через различимость меток (цвет $\Delta E_{00}$, контраст).
Единицы: безразмерная/бит.

## 5. Правило выбора без весов

Так как весовой метод отвергнут, сравнение — **объективное**:

1. **Доминирование (Парето):** модель лучше, если она не хуже по всем
   характеристикам и строго лучше хотя бы по одной.
2. Если Парето-оптимум не единственный — **лексикографический порядок**
   по заранее объявленному **приоритету** характеристик (приоритет
   задаётся не «на глаз», а постановкой задачи).
3. **Пороговые ограничения** — отсев по минимуму (например, $E \ge E_{min}$).

Это соответствует требованию «только числа и факты».
