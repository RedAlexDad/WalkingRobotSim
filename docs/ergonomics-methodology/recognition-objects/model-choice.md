## 2. Базовые расчётные величины (по архитектуре)

### 2.1. Свёрточный слой (CNN)

Число параметров и операций для слоя с ядром $k_h\times k_w$, входами
$C_{in}$, выходами $C_{out}$, выходной картой $H_{out}\times W_{out}$:

$$P_{conv} = k_h k_w C_{in} C_{out} + C_{out}$$

$$\mathrm{FLOPs}_{conv} = 2\,k_h k_w C_{in} C_{out} H_{out} W_{out}$$

(множитель 2 — умножение и сложение; $\mathrm{MACs}$ — без множителя 2).
Единицы: параметры — шт.; FLOPs — операций (или ГFLOP).

### 2.2. Линейный слой

$$P_{fc} = I\cdot O + O, \qquad \mathrm{FLOPs}_{fc} = 2\,I\,O$$

### 2.3. Трансформерный блок (RT-DETR)

Для блока с размерностью $d$ и длиной последовательности $n$, $\ell$
голов внимания:

- проекции внимания: $P_q = P_k = P_v = P_o = d^2$; итого
  $P_{att}^{proj} = 4d^2$;
- внимание: $P_{att}^{core}=0$ (параметров нет), FLOPs
  $\approx 4\,n^2 d$ (две матричные операции $n^2 d$);
- MLP (расширение $4d$): $P_{mlp} = 8 d^2$, FLOPs $\approx 16\,n d^2$;
- LayerNorm (2 шт.): $P_{ln} = 4d$.

$$P_{block} = 12 d^2 + 4d, \qquad
\mathrm{FLOPs}_{block} \approx 24\,n d^2 + 4\,n^2 d$$

### 2.4. Итог по модели

$$P = \sum_{\text{слоёв}} P_i, \qquad
\mathrm{FLOPs} = \sum_{\text{слоёв}} \mathrm{FLOPs}_i,
\qquad L = \text{число слоёв (глубина)}$$

## 3. Характеристики (конкретно)

### 3.1. Эффективность ($E$)

**Формула (аналитическая, без прогонов):**

$$E = \frac{1}{\mathrm{FLOPs}} \quad\text{или}\quad
E_{p} = \frac{1}{P}, \qquad E_{m} = \frac{1}{M_{model}}$$

где $\mathrm{FLOPs}$ — по §2, $P$ — число параметров, $M_{model}$ —
память модели.
**Единицы:** $1/\text{FLOP}$, $1/\text{шт.}$, $1/\text{байт}$ (чем
больше — тем эффективнее).

### 3.2. Читаемость ($C$)

**Формула:**

$$C = \frac{1}{\log_2(P+1)} \cdot \tau, \qquad
\tau = \begin{cases} 1 & \text{CNN/линейные (прозрачнее)}\\ 0.5 & \text{transformer (внимание менее прозрачно)}\end{cases}$$

где $P$ — число параметров, $\tau$ — коэффициент прозрачности типа
архитектуры.
**Единицы:** безразмерная (0…1), больше — читаемее.

### 3.3. Различимость / ёмкость разделения ($R$)

**Формула — через число линейных областей ReLU-сети** (Montúfar и др.,
2014). Для сети с глубиной $L$, входной размерностью $d$ и ширинами
$n_i$:

$$R \le \prod_{i=1}^{L-1} \sum_{j=1}^{d} \binom{n_i}{j}$$

Для одинаковой ширины $n$: $R = O\!\left(n^{\,d(L-1)}\right)$.

**Формула — через VC-размерность** (Bartlett и др., 2019) для сети с $W$
весами и глубиной $L$:

$$\mathrm{VCdim} = O\!\left(W\,L\,\log W\right)$$

**Единицы:** $R$ — число областей (шт.); $\mathrm{VCdim}$ — шт.

### 3.4. Однозначность класса ($O$)

**Формула:**

$$O = \frac{1}{k}, \qquad k = \text{число классов на один объект выхода}$$

Для однозначной классификации (softmax + argmax) $O=1$; для мультиметки
$O=1/k$.
**Единицы:** безразмерная (0…1).

### 3.5. Наглядность ($H$)

**Формула (по Хику–Хайману):**

$$H = \frac{1}{\log_2(k+1)}$$

где $k$ — число одновременно выводимых сущностей (меток).
**Единицы:** безразмерная (0…1), больше — нагляднее.

## 5. Правило выбора без весов

1. **Доминирование (Парето):** модель $A$ лучше $B$, если $A$ не хуже по
   всем характеристикам и строго лучше хотя бы по одной.
2. **Лексикографический** порядок при неединственном Парето-оптимуме —
   по приоритету характеристик (объявлен заранее).
3. **Пороговый отсев** по минимуму, например $E \ge E_{\min}$.

## 7. Числовой пример расчёта

### 7.1. Свёрточный слой (CNN)

Дано: $k=3$, $C_{in}=64$, $C_{out}=128$, $H_{out}=W_{out}=80$.

$$P = 3\cdot3\cdot64\cdot128 + 128 = 73\,856\ \text{шт.}$$

$$\mathrm{FLOPs} = 2\cdot3\cdot3\cdot64\cdot128\cdot80\cdot80
= 943\,718\,400 \approx 0{,}94\ \text{ГFLOP}$$

### 7.2. Линейный слой

Дано: $I=256$, $O=10$.

$$P = 256\cdot10 + 10 = 2\,570\ \text{шт.}, \qquad
\mathrm{FLOPs} = 2\cdot256\cdot10 = 5\,120$$

### 7.3. Трансформерный блок

Дано: $d=256$, длина последовательности $n=100$.

$$P_{block} = 12\cdot256^2 + 4\cdot256 = 787\,456\ \text{шт.}$$

$$\mathrm{FLOPs}_{block} \approx 24\cdot100\cdot256^2 + 4\cdot100^2\cdot256
= 157\,286\,400 + 10\,240\,000 = 167\,526\,400 \approx 0{,}17\ \text{ГFLOP}$$

### 7.4. Ёмкость (пример)

Одно скрытое ReLU-слоёв на $n=100$ нейронов, вход $d=10$:

$$R \le \sum_{j=0}^{10} \binom{100}{j} \approx 1{,}73\cdot10^{13}\
\text{областей}$$

Показывает, что ёмкость ($R$) растёт как $O(n^{d})$ для одного слоя и как
$O(n^{d(L-1)})$ для глубокой сети.
