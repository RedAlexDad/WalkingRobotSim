# gpu-rl-training — обучение RL-политики на GPU и перенос в gz-sim

Рабочая папка по **обучению RL-политики походки Go2 в GPU-симуляторе**
и последующему переносу в наш **gz-sim** (Rust-стек).

Контекст: предобученная политика NVIDIA (PhysX/Isaac) в наш gz-sim
**нулевым переносом не идёт** — оседает (подтверждено численно,
см. `run-log.md`). Модельный **Rust-TROT** в этом же мире работает
стабильно. Значит окружение исправно, а разрыв — «политика ↔ физика
gz-sim». Решение: обучить политику с **domain randomization** в
GPU-симуляторе и перенести в gz-sim.

| Файл | Что это |
|---|---|
| `plan.md` | план: среда, выбор GPU-фреймворка, метод, этапы, риски |
| `environment.md` | факты окружения (GPU, драйвер, CUDA, инструменты) |
| `README.md` | этот индекс |

Связанные материалы:

- `docs/gazebo-rl-vs-ik/` — план и журнал RL vs IK/TROT в Gazebo,
  оценка RTF и GPU, обзор готовых решений.
- `reports/gazebo-rl/2026-10-09_gazebo-rl-sim2sim.md` — отчёт
  sim-to-sim (перенос PhysX → gz-sim, отрицательный результат).
- `src/gazebo_sim/scripts/go2_policy_gz.py` — узел политики (точка
  интеграции обученной политики).
- `docs/rl-sar/`, `reports/rl-sar/` — отдельная ветка работ с rl_sar
  (RL-походка в Gazebo Classic).
