сборки (cu121/cu124) не запустятся.

## 4. Что это значит для выбора фреймворка

`sm_120` отсекает заведомо старые версии фреймворков. При развёртывании
нужно проверять поддержку Blackwell:

| Фреймворк | Требование под `sm_120` | Замечание |
|---|---|---|
| Isaac Lab / Isaac Sim | Isaac Sim ≥ 4.5 (CUDA 12.8, драйвер ≥ 570) | тяжёлая установка |
| MuJoCo Playground (MJWarp) | JAX + CUDA 12.8+ (`jaxlib` свежий) | лёгкий старт через `uv` |
| Genesis | PyTorch cu128+ | новый проект |
| Newton (Warp) | NVIDIA Warp + CUDA 12.8+ | самый новый |

## 5. Проверки перед стартом (чек-лист)

- [ ] `nvidia-smi` видит GPU, драйвер ≥ 570, CUDA ≥ 12.8.
- [ ] Контейнер/venv видит GPU (`torch.cuda.is_available()` /
      `jax.devices()` показывает GPU).
- [ ] Версия фреймворка собрана под `sm_120` (иначе — ошибка ядра).
- [ ] Достаточно VRAM под батч сред (16 ГБ — ориентир: сотни сред Go2).
