## Назначение папки

Подготовка научной статьи для конференции PIERE 2026 (публикация в
Scopus, под эгидой IEEE Siberia). Папка содержит обоснование, черновик
статьи, требования, инструкции и локальные копии источников.

## Как писать статью (быстрый порядок)

1. Прочитать `why-article.md` (разделы 7 «Новизна» и 28 «Практическая
   польза») — для Introduction/Discussion.
2. Взять `draft-article.md` как каркас.
3. Заменить все значения ⚠️ реальными из логов эксперимента.
4. Вставить цитаты/числа из `refs/` в Related Work.
5. Оформить строго по `ieee-template-notes.md`, вставив текст в
   `PIERE2026__full_paper_template.docx`.
6. Проверить по `requirements.md` (объём, слова, структура).
7. Подать по `submission-form.md`.
