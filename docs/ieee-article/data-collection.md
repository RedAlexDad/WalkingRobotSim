### 3.1. Архитектура связки (для раздела System Architecture)

- Rust-контроллер (`quadropted_core`) в контейнере → ROS2 →
  `/robot1/joint_group_controller/commands` → адаптированный пакет
  `go2_isaac_ros2` (Go2SubNode) → IsaacLab env → PhysX (GPU) → Go2.
- Причина перехода на Float64MultiArray: собранные типы `unitree_go`
  несовместимы с rclpy Isaac (type_support null, rosidl 4.6.9 vs 4.6.7).

## 6. Протокол эксперимента (единый для обоих контроллеров)

Чтобы сравнение было корректным, **оба** контроллера запускаются в
идентичных условиях:

- робот: Unitree Go2 (ассет IsaacLab `go2.usd`);
- среда: Isaac Sim 6.0.1 / IsaacLab 3.0;
- поверхность: плоская, трение 1.0;
- команда: vx = 0.3 м/с, vy = 0, wz = 0;
- длительность: не менее 10 с (2000 шагов), лучше 20–30 с;
- старт: STANDING;
- повторов: не менее 3 прогонов на контроллер (для среднего/std);
- фиксировать: X,Y,Z, roll/pitch/yaw, q, qdot, команды суставов,
  время шага/частоту.

**Метрики:** средняя скорость, пройденное расстояние, Std(Z), дрейф |Y|,
max|roll|, max|pitch|, время до устойчивой походки, CoT, число шагов до
сбоя.

**Примечание:** сравнение при «родных» PD каждого режима (25 vs 75);
опционально — серия с выровненными PD.

## 7. План сбора данных (по шагам)

1. **Телеметрия.** ✅ Реализовано:
   - `src/isaac/telemetry.py` — логгер CSV (корпус, углы, суставы, команды);
   - `src/isaac/run_sim_telemetry.py` — лаунчер IsaacLab с записью;
   - `src/isaac/run_isaaclab.sh` — теперь запускает лаунчер с телеметрией;
   - `src/isaac/analyze_telemetry.py` — расчёт метрик и графиков из CSV.
2. **Серия IK/TROT.** 3 прогона по 20–30 с, сохранить CSV.
3. **Серия RL.** 3 прогона с командой vx=0.3, сохранить CSV.
4. **Обработка.** `analyze_telemetry.py` → метрики (скорость, Z, std,
   дрейф, углы, CoT).
5. **Возмущения.** Толчок сбоку, скользкая поверхность — качественно +
   численно, если реализуемо.
6. **Иллюстрации.** Скриншоты GUI, графики X(t)/Y(t)/Z(t)/углы.
7. **Сведение.** Заполнить таблицы 1–2 черновика, убрать ⚠️-заглушки.

### 7.1. Как запускать телеметрию

```bash
# серия IK/TROT (наш Rust-контроллер)
GO2_TELEMETRY_TAG=ik bash src/isaac/run_isaaclab.sh --headless

# серия RL (политика NVIDIA) — тег rl
GO2_TELEMETRY_TAG=rl bash src/isaac/run_isaaclab.sh --headless

# разбор записанных CSV
python3 src/isaac/analyze_telemetry.py logs/isaac/telemetry_ik_*.csv \
        logs/isaac/telemetry_rl_*.csv --json logs/isaac/summary.json --plot
```

Переменные окружения:
- `GO2_TELEMETRY=0` — отключить запись;
- `GO2_TELEMETRY_TAG=ik|rl` — метка в имени файла;
- `GO2_TELEMETRY_CSV=/path.csv` — явный путь к файлу.

- Решение: перезагрузить хост (или перезагрузить модули nvidia), затем
  повторить прогоны. Контейнер `walking_robot_sim` работает.
