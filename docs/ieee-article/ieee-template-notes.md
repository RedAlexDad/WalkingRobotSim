# Требования к оформлению по шаблону IEEE (PIERE 2026)

**Источник:** `PIERE2026__full_paper_template.docx`
(загружен в `docs/ieee-article/`, 2026-09-07)
**Статус:** выжимка правил оформления из шаблона IEEE

---

## 1. Объём и язык

- Полный текст — не менее **3 страниц** (без учёта списка источников).
- Не более **6 страниц** (включая список источников).
- Больше 6 страниц — доп. плата (не более 4 доп. страниц).
- Язык — **только английский** (использование кириллицы запрещено).
- Список источников — не менее **8**.
- Самов цитирование — не более **3** ссылок.
- Уровень английского — продвинутый, избегать длинных выражений.

## 2. Аннотация (Abstract)

- Объём **150–250 слов**.
- В аннотации кратко изложить основные результаты.
- **ЗАПРЕЩЕНО**: символы, специальные знаки, сноски, математические
  формулы в названии и аннотации.

## 3. Ключевые слова (Keywords)

- Количество — **не менее 5**.
- Пример из шаблона: component, formatting, style, styling, insert.

## 4. Плагиат

- По правилам IEEE Publication Services and Products Board критический
  уровень плагиата (включая самоплагиат, без учёта ссылок) при проверке
  **CrossCheck Portal — 20%**, выше нельзя.

## 5. Разделы статьи

Текст делится на секции; рекомендуется:

- **Introduction** — должна включать постановку задачи (problem
  statement);
- **Theory**;
- **Experimental Results**;
- **Conclusions**.

Допускаются и другие заголовки секций при необходимости.

## 6. Оформление (из шаблона)

- Не изменять поля, ширину колонок, межстрочный интервал, шрифты —
  всё задано шаблоном.
- Не использовать жёсткие табуляции; ограничить жёсткие переносы строк
  (один перенос в конце абзаца).
- Не добавлять нумерацию страниц и заголовков вручную — шаблон сделает.
- Перед оформлением написать текст отдельно, затем вставить в шаблон.

### 6.1. Сокращения и аббревиатуры

- Определять при первом использовании в тексте (даже если уже
  определены в аннотации).
- IEEE, SI, MKS, CGS, sc, dc, rms — не требуют определения.
- Не использовать сокращения в названии и заголовках без необходимости.

### 6.2. Единицы измерения

- Использовать SI (MKS) или CGS; SI предпочтительны.
- Английские единицы — только как вторичные, в скобках.
- Не смешивать SI и CGS.
- Не смешивать полные названия и сокращения единиц.
- Ноль перед десятичной точкой: «0.25», не «.25».
- Финансирование указывать отдельным блоком (если есть).

### 6.3. Уравнения

- MS Equation / MathType.
- Нумеровать только те, на которые есть ссылки в тексте; номер — справа
  в скобках (1).
- Курсив для латинских символов, греческие — прямым шрифтом.
- Использовать «(1)», не «Eq. (1)» (кроме начала предложения).
- Определять символы до или сразу после уравнения.

### 6.4. Частые ошибки

- «data» — множественное число.
- Знаки препинания в кавычках — по американским правилам.
- «inset», а не «insert» (график внутри графика).
- «essentially» не употреблять в значении «approximately».
- «non» присоединяется без дефиса.
- «et al.» — без точки после «et».
- «i.e.» — that is; «e.g.» — for example.
- Стиль: [8] — отличный справочник по научному стилю.

## 7. Авторы и аффилиация

- Максимум **6 авторов** (минимум 1).
- Порядок авторов — слева направо, затем вниз на следующую строку
  (будет использован при цитировании и индексации).
- Аффилиации — максимально кратко (без дифференциации кафедр одной
  организации).
- Для >3 авторов — добавлять горизонтально, при необходимости второй ряд.
- Для <6 авторов — удалить лишние строки, изменить число колонок.

### Формат аффилиации (из шаблона)

```
line 1: Given Name Surname
line 2: dept. name of organization (of Affiliation)
line 3: name of organization (of Affiliation)
line 4: City, Country
line 5: email address or ORCID
```

## 8. Рисунки и таблицы

- Рисунки — вверху/внизу колонок, не в середине.
- Рисунки желательно 300 dpi TIFF/EPS, все шрифты встроены.
- Подписи к рисункам — под рисунком; заголовки таблиц — над таблицей.
- Использовать сокращение «Fig. 1», даже в начале предложения.
- Подписи рисунков — 8 pt Times New Roman.
- Оси графика подписывать словами, единицы в скобках:
  «Magnetization (A/m)», не «A/m».

## 9. Ссылки (References)

- Нумеровать подряд в квадратных скобках [1], [2], …
- Пунктуация предложения следует после скобки [2].
- Не использовать «Ref. [3]» или «reference [3]» (кроме начала
  предложения: «Reference [3] was the first ...»).
- Если авторов шесть и более — перечислить всех; иначе «et al.» не
  использовать.
- Неопубликованные работы — «unpublished»; принятые — «in press».
- В названии статьи капитализировать только первое слово (кроме имён
  собственных и символов элементов).
- Для переводных/не-латинских изданий: английское цитирование первым,
  затем оригинал.
- Диапазоны ссылок — без en dash: «[1], [2], [3], [4]», не «[1]–[4]».

### Примеры форматов (из шаблона)

```
[1] G. Eason, B. Noble, and I. N. Sneddon, "On certain integrals ...",
    Phil. Trans. Roy. Soc. London, vol. A247, pp. 529–551, April 1955.
[2] J. Clerk Maxwell, "A Treatise on Electricity and Magnetism", 3rd ed.,
    vol. 2. Oxford: Clarendon, 1892, pp. 68–73.
[4] Y. Yorozu, et al., "Electron spectroscopy studies ...", IEEE Transl.
    J. Magn. Japan, vol. 2, pp. 740–741, August 1987.
[8] M. Young, The Technical Writer's Handbook. Mill Valley, CA:
    University Science, 1989.
[12] V. Puzyrev, S. Koric, and S. Wilkin, "Evaluation of parallel direct
     sparse linear solvers ...", Comput. Geosci., vol. 89, pp. 79–87, 2016.
[13] Process Software Corp., "Intranets: Internet technologies ...",
     Presented at INET'96 Annu. Meeting. [Online]. Available:
     http://www.process.com/Intranets/wp2.htp
[14] K. Klionovski, "Broadband dual-band microstrip antenna," (in Russian),
     RU Patent Utility Model 167296, Dec. 27, 2016.
```

## 10. Финальное замечание

Шаблон IEEE содержит пояснительный текст-инструкцию. **Перед подачей весь
шаблонный текст должен быть удалён** из статьи, иначе публикация может
быть отклонена.

---

## Чек-лист оформления

- [ ] Удалён весь пояснительный текст шаблона
- [ ] 3–6 страниц, ≥2500 слов
- [ ] Английский язык
- [ ] Abstract 150–250 слов (без формул/символов)
- [ ] Keywords ≥5
- [ ] References ≥8 (рекомендуется 20–30), самов цитирование ≤3
- [ ] Плагиат ≤20%
- [ ] Рисунки 300 dpi, подписи корректны
- [ ] Единицы SI, ноль перед десятичной точкой
