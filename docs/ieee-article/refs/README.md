тексты + аннотации), чтобы ссылаться на них без доступа к интернету.

## Как получено

Файлы скачаны скриптом `scripts/fetch_arxiv_refs.py` (из корня репозитория):

```bash
python3 scripts/fetch_arxiv_refs.py --out docs/ieee-article/refs \
  2501.16590 2108.10470 2606.14433 2607.18135
```

Скрипт:
- скачивает аннотацию (страницу `abs`) и полный HTML-текст (`html`);
- конвертирует HTML в Markdown на стандартной библиотеке Python;
- повторяет запросы с экспоненциальной задержкой при сетевых ошибках;
- очищает полный текст от служебных элементов arXiv (шапка, подвал,
  баннеры, формы);
- сохраняет аннотации без HTML-сущностей и тегов.

## Проверка ссылок

Каждая ссылка проверена (HTTP 200, страница содержит корректный
arXiv-id и заголовок работы). DOI имеют вид `10.48550/arXiv.<id>`.

## Примечание

ID `2607.18135` необычен (формально код года `2607`), но страница arXiv
открывается и содержит указанный заголовок. Перед цитированием в статье
рекомендуется дополнительно перепроверить этот источник (возможен
артефакт тестовой выдачи arXiv).
