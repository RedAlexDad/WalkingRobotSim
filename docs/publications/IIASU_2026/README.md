## Метаданные: УДК и SPIN-код

**УДК.** Присваивается **автором** по классификатору (не выдаётся после
публикации). Проверено по классификатору TeaCode: **004.93** —
«Распознавание и преобразование образов»; уточняющий код —
**004.93'1** «Распознавание образов. Опознавание образов». В статье
используется 004.93.

**Рубрика ГРНТИ.** В анкете eLibrary выбирается из тематического
рубрикатора. Для темы подходит **28.23.00 «Искусственный интеллект»**
(раздел 28 «Кибернетика»); при наличии подрубрик — «Нейронные сети» или
«Распознавание образов». Блок 20.xx — «Информатика» (общие вопросы), для
машинного обучения не подходит.

**SPIN-код.** Присваивается при **регистрации в eLibrary.ru** (бесплатно):
регистрация → профиль автора → SPIN (формат `1234-5678`). Без регистрации
кода нет. Если к подаче не успели — оставить прочерк и добавить позже:
на подачу не влияет, но для индексации в РИНЦ желателен.

## Быстрый порядок

1. Собрать текст по `plan.md` из материалов `docs/ergonomics-methodology/`
   (см. `source-materials.md`).
2. По шаблону: УДК, заголовок (6–15 слов), авторы, аннотация
   (650–1000 знаков), ключевые слова (5–7), EN-блок; разделы
   **Введение / Материалы и методы / Результаты / Обсуждение / Заключение**;
   `.docx`, 4–6 стр., ≥6000 знаков.
3. Оформить **≤2 таблицы** и **≤5 рисунков**; список источников (ГОСТ, ≥5).
4. Проверить заимствование (≤20%).
5. Заключение об открытом опубликовании через ЦПР.
6. Подать статью и выступить (28.10.2026).
