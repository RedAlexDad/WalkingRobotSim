## Зачем эта папка

Рабочая папка по русскоязычной статье в сборник **РИНЦ** конференции
ИИАСУ-2026 (секция «Эргономика и дизайн»). Здесь план написания, формальные
требования, правила оформления и организационные шаги подачи.

Источник содержания — исследование по эргономике представления
результатов распознавания (`docs/ergonomics-methodology/`).

## Быстрый порядок

1. Шаблоны и требования скачаны → `template/`; выжимки — в
   `requirements.md` и `template-notes.md`.
2. Собрать текст по `plan.md` из материалов
   `docs/ergonomics-methodology/` (см. `source-materials.md`).
3. По шаблону: УДК, аннотация (650–1000 знаков), ключевые слова (5–7),
   EN-блок; разделы **Введение / Материалы и методы / Результаты /
   Обсуждение / Заключение**; `.docx`, 4–6 стр., ≥6000 знаков.
4. Оформить **≤2 таблицы** и **≤5 рисунков**, список источников
   (ГОСТ, ≥5).
5. Заключение об открытом опубликовании через ЦПР (до 31.10.2026).
6. Подать статью в личном кабинете до 31.10.2026.
