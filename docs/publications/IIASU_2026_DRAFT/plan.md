## 1. Тема и название

**Рабочая тема:** Эргономическое обоснование представления результатов
распознавания объектов оператору мобильного робота.

**Варианты названия (рус., 6–15 слов, без формул):**

1. «Эргономическое обоснование представления результатов распознавания
   объектов оператору мобильного робота»
2. «Модель информационной цепочки для эргономического обоснования
   представления результатов распознавания»

**Вариант названия (англ.):** «Ergonomic Justification of Object
Recognition Presentation to a Mobile Robot Operator».

Название фиксируется до запроса заключений и **не меняется**.

## 2. Идея и научная новизна

- Эргономика рассматривается не декларативно, а **через расчёт**:
  сквозная **информационная цепочка** «кадр → захват → детектор →
  представление → оператор → решение» считается по модели, и вклад
  звена «представление» виден в общем итоге.
- Обоснование строится **от теории к модели**, эксперимент — только
  проверка.
- Новизна — **количественная связь представления результата
  распознавания с потерями** всей цепочки и с калибровкой доверия
  оператора.

## 3. Структура статьи (под требования ИИАСУ)

Статья строится строго по разделам шаблона.

### 3.1. Введение

- Роль распознавания объектов в работе оператора мобильного робота.
- Проблема: результат распознавания доходит до оператора с потерями;
  представление влияет на доверие и решение.
- Постановка: сузить объект до звена «экран → оператор» в цепочке
  распознавания.
- Цель: дать эргономическое обоснование представления через расчёт
  цепочки.

### 3.2. Материалы и методы

- **Информационная цепочка из 5 звеньев** (схема 1).
- **Модель:** итоговая точность $A = \prod_i a_i$; вклад звена в потерю
  $\ell_i = (1-a_i)/\sum_j (1-a_j)$.
- **Метрики звеньев:** детектор — precision/recall/F1; представление —
  ECE и различимость; оператор — $d'$, Хик–Хайман, Фиттс; свежесть — AoI.
- **Различимость:** $\Delta E_{00}$ (цвет), контраст по WCAG, угловой
  размер; различимость по Веберу.
- Данные звеньев — из литературы/датасетов (без фокус-групп и
  экспертизы).

### 3.3. Результаты

- Числовой расчёт цепочки для выбранного примера (сцена с несколькими
  детекциями разной уверенности).
- Вклады звеньев $\ell_i$; демонстрация, что неявная уверенность ведёт к
  ложному доверию, а явная — повышает $a_3$ и итог $A$.
- Таблица «звено/коэффициент/показатель/потери» и сводка расчёта.

### 3.4. Обсуждение

- Сопоставление с эргономическими основаниями (SDT, ECE, Хик, Фиттс,
  Вебер, CIE, AoI).
- Что даёт расчёт для проектирования интерфейса (рекомендации).
- Ограничения модели.

### 3.5. Заключение

- Сформулированное эргономическое обоснование представления.
- Практические рекомендации (показ уверенности, различимость,
  приоритизация).
- Направление развития (связь с ВКРМ/научруком Каневым).
