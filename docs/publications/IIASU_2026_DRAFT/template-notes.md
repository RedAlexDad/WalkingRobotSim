# Оформление по шаблону РИНЦ (ИИАСУ-2026)

**Источник:** `template/proceedings_template.docx`,
`template/Требования_к_статьям_РИНЦ.docx`
**Статус:** заполнено по факту скачанных документов

---

## 1. Макет страницы

- А4, все поля **2 см**.
- Шрифт **Times New Roman 12**, интервал **полуторный**.
- Гиперссылки и разрывы разделов внутри текста **запрещены**.
- Файл — **.docx**.

## 2. Порядок метаданных (строго по шаблону)

```
УДК <код>

Заголовок статьи (полужирный)

Фамилия Имя Отчество1  e-mail
Фамилия Имя Отчество2(*)  e-mail
SPIN-код: <если есть>

1 Организация, Город, Страна
2 Организация, Город, Страна

Аннотация. ...

Ключевые слова: ..., ..., ..., ..., ...

Заголовок на английском

Author Name1  e-mail

1 Organization, City, Country

Abstract. ...

Keywords: ..., ..., ...

Введение. ...
Материалы и методы. ...
Результаты. ...
Обсуждение. ...
Заключение. ...

Список источников
[1] ...
```

## 3. Заголовки разделов

- В подбор к тексту, **полужирным**, отделяются **точкой**:
  «**Введение.** текст…», «**Материалы и методы.** …».
- Отдельных строк-заголовков и нумерации разделов — нет.

## 4. Формулы

- Equation / MathType любой версии либо встроенный редактор Word.
- Кегль как в основном тексте.
- Нумеровать **только** те формулы, на которые есть ссылки в тексте;
  номер справа в скобках.
- Все величины раскрывать при первом упоминании.

## 5. Таблицы

- **До 1–2 шт.**, не более **20%** объёма статьи.
- Заголовок **над** таблицей, нумерация по порядку упоминания:
  `Таблица 1` (пустая строка) `**Заголовок таблицы**`.
- Не дублировать графики таблицами.

## 6. Рисунки

- **До 4–5 шт.**; вставлять сразу после абзаца первого упоминания.
- Подрисуночная подпись **под** рисунком.
- Графические элементы сгруппированы; масштабируемость без потери
  качества; за качество отвечает автор.

## 7. Ссылки и список источников

- В тексте: `[7]` или `[7, с. 17]`; в одних скобках **≤3** источников.
- Список — по порядку упоминания, **на языке оригинала**, **≥5** позиций.

**Журнал/конференция (рус.):**

## 9. Что проверить перед сдачей

- [ ] Убрать весь пояснительный текст шаблона
- [ ] Поля/шрифт/интервал не изменены
- [ ] Разделы — в подбор, полужирным, с точкой
- [ ] Таблиц ≤2, рисунков ≤5, подписи на месте
- [ ] Ссылки `[n]`, в скобках ≤3, список по порядку
- [ ] EN-блок (заголовок/авторы/аннотация/ключевые) заполнен
