# КАПП-2026 — требования и чек-лист

## Требования конференции

| Параметр | Значение |
| --- | --- |
| Формат участия | очный, **дистанционный** |
| Организационный взнос | **отсутствует** |
| Язык | русский, английский |
| Публикация | сборник статей, индексируется **РИНЦ** |
| Секция | **4) Оптимизация проектных решений** |
| Отбор в сборник | решение **Программного комитета** по результатам **рецензирования** |
| Для студентов/аспирантов | можно загрузить **рецензию научного руководителя** (обязательно с его контактами) |

## Ключевые даты

| Этап | Дата | Статус |
| --- | --- | --- |
| Открытие регистрации | 01.06.2026 | прошло |
| Приём заявок на участие **с докладом** | до 23.10.2026 | ⬜ |
| Конференция (доклад) | 30.10.2026 | ⬜ |
| Подача статьи в сборник | до 06.11.2026 | ⬜ |
| Рецензия научного руководителя | вместе со статьёй | ⬜ |

## Чек-лист подготовки

- [ ] Согласовать тему и секцию с научным руководителем.
- [ ] Скачать **шаблон оформления тезисов/статьи** (ссылка в информационном
      сообщении) и привести черновик к шаблону.
- [ ] Подать **заявку на участие с докладом** (до 23.10.2026).
- [ ] Подготовить доклад (≈10 мин) — на основе `draft-article.md`.
- [ ] Написать статью по материалам доклада (до 06.11.2026).
- [ ] Получить **рецензию научрука** (с контактами).
- [ ] Загрузить статью + рецензию.

## Замечания
- Отдельно пройти **регистрацию бейджа** — если требуется организаторами
  (уточнить у секретаря).
- **Не дублировать** эту работу в другом сборнике (ИИАСУ и т. п.).
