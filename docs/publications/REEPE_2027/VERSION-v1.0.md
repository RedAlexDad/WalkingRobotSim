  для Unitree Go2 в Isaac Sim / IsaacLab.
- Скорость: RL 0.231 м/с, IK 0.215 м/с (n=3).
- CoT: RL 2.84, IK 2.83 ± 0.41.
- Устойчивость: RL — roll 2.3°, дрейф 0.37 м; IK — roll 27.8°, дрейф 1.09 м.

- 5 дефектов интеграции + архитектурный крен через hip (roll 50→8°).
- Научные положения P1–P4.
