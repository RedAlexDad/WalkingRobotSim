## 1. Выбор секции

**Рекомендовано: «Computing, Signal Processing, and Analysis»** — суть
работы про **обученную политику (RL) vs модельный контроллер** и анализ в
симуляции (computer engineering / signal processing and analysis).

Альтернатива: **«Nuclear and Mechanical Science Applications»** — если
делать акцент на механике/робототехнике (походка, приводы).

Не подходит: Transportation, Power/Energy, Components, Fields/Waves,
Medical, Engineering Management, Water-Energy.

> Если в выпадающем списке ЛК будет отдельная секция «Robotics» /
> «Control Systems» — выбирать её.

## 3. Формальные требования (официальные)

| Параметр | Требование |
| --- | --- |
| Язык | только **английский** |
| Шаблон | **IEEE** (`template/шаблон_одна_аффилиация.docx`) |
| Объём | **5–6 страниц**; до 9 — платно (20 USD / 1500 ₽ за стр.) |
| Название | **не более 15 слов**, кратко и точно |
| Сведения об авторах | имя, уч. степень/звание, аффилиация, **полный почтовый адрес**, e-mail |
| Abstract | **75–150 слов** |
| Ключевые слова | **3–7 слов** |
| Введение | обзор темы и цели (актуальность, значимость, краткий обзор литературы) |
| Постановка задачи | чёткая формулировка исследовательского вопроса |
| Теоретическая часть | обоснование исследовательского вопроса |
| Результаты и обсуждение | анализ, предложения, кейсы, результаты экспериментов |
| Conclusion | не короче **100 слов** |
| Список литературы | **20–30 позиций**; в одних `[ ]` — **≤3** источника; **самоцитирований ≤3** |
| Антиплагиат | заимствования **≤20%** (иначе отклонение) |
| Авторы | **не более 6** |
| От одного автора | **не более 3** статей в одном выпуске |
| Рецензирование | single-blind |
| Доклад | **только очный**, онлайн-выступлений **нет** |

Источники требований: `template/REEPE_Перечень_требований.docx`,
`template/шаблон_одна_аффилиация.docx` (локальные копии), сайт REEPE
(`AUTHOR KIT`, `reepe.mpei.ru`).

**Критично:**
- Статьи, **не представленные очно**, **не попадают в IEEE Xplore**.
- Работа должна быть **оригинальной** и **не подаваться** в другое место
  (нельзя дублировать в ИИАСУ / КАПП).
- В заключениях указывать **названия статьи на русском и английском**,
  которые **не будут меняться**.

## 5. Шаги

1. **Название (EN/RU)** зафиксировать — совпадает в статье и заключениях.
2. **Секция** — выбрать «Computing, Signal Processing, and Analysis».
3. **Данные**: свести метрики RL vs IK/TROT.
4. **Текст под IEEE**: Introduction, Related Work, Method, Experiments,
   Results, Discussion, Conclusion.
5. **Abstract** 75–150 слов, без формул; **список литературы 20–30
   позиций** (IEEE), самоцитирований ≤3.
6. **Рисунки/таблицы** — читаемы в ч/б.
7. **Вёрстка** 5–6 страниц по шаблону IEEE.
8. **Заключения** (экспертное + экспортное) через ЦПНП; названия RU/EN
   неизменны.
9. **Подача** статьи и заключений.
