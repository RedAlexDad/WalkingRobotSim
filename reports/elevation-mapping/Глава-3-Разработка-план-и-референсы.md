## Простая задача для симулятора

> *"Немного улучшить существующее"* (научрук)

**Тема:** Разработка модуля Elevation Mapping и terrain-aware планирования в ROS 2 Jazzy

### Что делаем

1. **Python модуль** для фильтрации облаков точек LiDAR (ground/non-ground)
2. **Построение карты высот (Digital Elevation Model)** в реальном времени
3. **Функция стоимости пути** с учётом рельефа (градиент поверхности)
4. **Адаптация походки** по типу местности
5. **Тестирование** в симуляции Gazebo с Unitree Go1/Go2

## Готовые референсы с GitHub

### 1. elevation_mapping_cupy (ETH Zurich / ANYbotics) ⭐947

**Ссылка:** https://github.com/leggedrobotics/elevation_mapping_cupy

- GPU-ускоренное построение карты высот
- **v2.1.0 (Feb 2026) — ROS 2 Jazzy!** Идеально подходит
- Python + C++ + CuPy (CUDA)
- Фичи: visibility cleanup, height drift compensation, traversability filter
- Поддержка Multi-Modal Elevation Map (MEM)
- Есть Docker, тесты, RViz

**Как используем:**
- Берём как основу для модуля построения карты высот
- Адаптируем под Unitree в Gazebo
- Добавляем ground segmentation

### 2. grid_map (ANYbotics) — основа elevation_mapping

**Ссылка:** https://github.com/anybotics/grid_map

- C++ библиотека для многослойных grid-карт
- Встроено: normal vectors, roughness, traversability filters
- RViz плагин для визуализации 3D поверхности
- Используется внутри elevation_mapping

### 3. Fast ground segmentation (ROS1, но алгоритм)

**Ссылка:** https://github.com/VincentCheungM/Run_based_segmentation

- Run-based segmentation + Ground Plane Fitting
- Алгоритм из статьи "Fast segmentation of 3D point clouds" (Zermas 2017)
- Разделение ground/non-ground для LiDAR
- Портировать на ROS 2 Jazzy

### 4. pointcloud_to_laserscan (ROS 2 Rolling)

**Ссылка:** https://github.com/ros-perception/pointcloud_to_laserscan

- ROS 2 пакет, конвертация PointCloud2 → LaserScan
- Можно использовать как промежуточный шаг

## Какие метрики собирать

### Accuracy карты высот
- **RMSE** (Root Mean Square Error) — отклонение карты от ground truth
- **MAE** (Mean Absolute Error)
- **Max Error** — максимальное отклонение

### Производительность
- **FPS** карты (Hz) — как часто обновляется elevation map
- **Latency** — задержка от LiDAR → карта (ms)
- **GPU/CPU usage**

### Качество сегментации (если прикрутим нейросеть)
- **IoU** (Intersection over Union) по классам terrain
- **Accuracy** по классам

### Terrain-aware planning
- **Длина пути** (м) — сравнение с Nav2 baseline
- **Время прохождения** маршрута
- **Энергозатраты** (интегральная мощность)
- **Количество остановок/реколлизий** на сложном рельефе
- **Угол наклона** при движении — средний, макс
